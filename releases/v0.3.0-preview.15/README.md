# WorkPivot 0.3.0-preview.15

右侧由“成果区”改为三个区域：

- 任务监控：展示当前账号的多个任务和当前任务步骤；完成项为绿点、删除线，进行中为蓝点。任务恢复运行时清除上一轮完成标记，侧栏定期刷新。
- 产物：记录执行过程中新增或修改的文件，排除上传附件、隐藏目录和依赖目录。新增产物执行中可见；下载经过账号、任务和文件路径校验。升级前未建立产物索引的旧任务不会凭空列出输入文件。
- 技能与 MCP：展示当前任务实际可用且未停用的技能；目前后台没有 MCP 集成，如实显示未接入服务。

桌面客户端新增产物打开能力：仅向已连接服务下载已授权文件，在独立缓存副本中用默认本地软件打开；不覆盖上次打开的本地文件，也不会自动回写服务端。支持 docx/xlsx/pptx/pdf/txt/md/csv/json/png/jpg/jpeg/webp，直接打开上限 50MB；脚本、可执行文件、快捷方式和含宏 Office 文件不自动打开。浏览器与旧客户端可下载后自行打开。

Windows 安装包：installers/WorkPivot-Setup-0.3.0-preview.15.exe。

WSL 已备份后由 preview.14 更新到 preview.15，健康检查通过。类型检查、Lint、前端与客户端构建、依赖边界通过。Windows 产物专项 W27 25/25；Linux W26 61/61 + W27 25/25，测试容器无网络、无宿主挂载、无 Docker socket。黑白主题浏览器模拟界面验证完成，新客户端独立配置启动退出码 0。下载到本地流程已测，未自动启动实际 Office 软件。
