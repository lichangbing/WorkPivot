# 变更日志

所有对外发行版本的变更记录。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)。每个版本发布时同步在其 `vX.Y.Z/RELEASE-NOTES.md` 中写详细说明。

## [Unreleased]

### 变更

- 三层记忆改为每轮识别个人、项目、任务，满十轮补充整理；无冲突新增自动保存，修改、合并和冲突逐条确认。
- 同步聊天系统提示、十轮分析提示和记忆管理界面，消除旧确认规则歧义。
- 每日北京时间 12:00 刷新额度，发送完成后即时同步剩余次数。
- 新增安全 HTML 直接生成 PDF，并支持可选 Office → PDF。
- 管理后台增加注册策略、用户状态、每日额度、账号停用和会话撤销；schema v61。
- 外网 HTTPS、Capacitor 来源白名单和 Android 独立内测签名 APK 下载入口。
- 每轮自动加载相关个人、项目和任务记忆，失败不阻断聊天。
- 项目/任务增加跨终端工作区 SSE，同一任务的回复、工具步骤和审批从持久事件流同步；schema v62。
- Android 1.2 调整发送按钮尺寸和布局稳定性，并接入工作区同步。
- 新增项目级“业务事实”：业务对象、标识/别名、事实与关系版本、证据、冲突确认、双时态检索和 Agent 自动召回；schema v63。
- Web 与手机增加业务事实入口，支持查看当前值、历史证据、逐条确认冲突、新增事实和关系。
- Android 1.3（versionCode 4）加入项目业务事实列表、自动提取开关和逐条冲突确认。
- 桌面客户端 0.3.0-rc.2 默认连接正式域名；登录首页增加 Windows 便携包和 Android APK 直链。
- 数据库会话新增持久化澄清、计划审批、动作授权、成果验收和运行中消息分流；同一运行单阻塞队列，计划可修改，高风险动作逐次确认。
- 运行中相关消息更新当前上下文并重新规划；无关请求进入后续队列，当前任务完成后自动执行下一轮。待执行消息支持撤销和跨端恢复。
- 运行检查点保存模型消息、步数预算、资源范围、工具派发、计划、交互和待执行请求；中断恢复不重放未知副作用的工具调用。

### 修复

- 修复普通 HTTP IP 访问下消息和附件发送被 `crypto.randomUUID()` 阻断。
- 修复空读取范围阻断记忆提取和十轮分析的问题。
- schema v60 增加记忆自动保存来源，支持审计区分 `auto` 与 `user`。
- 修复数据库模式公开自助注册未受管理员策略控制的问题。
- 修复右侧工作区 PDF iframe 因 Chrome 禁止 sandbox 内 PDF 阅读器而显示“This page has been blocked by Chrome”的问题。

### 文档

- 新增 RC 发布门禁记录，明确技术门禁、外部设备/IdP 条件和未完成的长稳要求。
- 新增加权 HTTP/SSE 接口总览，统一鉴权、幂等键、revision 乐观锁、资源范围、事件类型和错误恢复口径。
- README、项目介绍、PRD、系统总览、数据架构与项目状态统一到 `v0.3.0-rc.3` / schema v70；历史部署记录保留原时点信息。

## [v0.3.0-rc.4] - 2026-11-04

### 新增

- 完成文档只读增强 RO-1～RO-6：预览/读取分离、派生契约、失败分级、结构化读取、扫描件文本层和版本预览元数据。
- Office 预览返回源/PDF/转换器/字体包哈希、阶段、耗时、生成时间和文本层状态；新增预览元数据接口。
- 新增固定原始版本结构化读取接口，支持 DOCX/XLSX/PPTX 对象、工作表、区域、UTF-16 偏移和有界续页。

### 变更

- 预览缓存 key 绑定版本、源文件哈希、转换器版本和字体包哈希。
- 前端预览能力不可用时引导下载原件，系统故障才提供重试。
- schema v71 增加 `document_processing.has_text_layer` 和 `document_versions.preview_*` 元数据。

### 修复

- 防止预览派生 PDF 被误用为 Agent 读取、知识入库或业务事实证据。
- 扫描 PDF 不再把 OCR 文本冒充原生文本层。
- 修复右侧预览和共享浏览器被中间块级容器压缩的问题；预览、PDF iframe 和浏览器画面现在填满工作区纵向可用空间。

### 验证

- PostgreSQL 852/852；解析元数据 37/37；文档预览、工作区 UI、TypeScript、ESLint 和 Web 构建通过。
- RC.4 按要求部署到本地测试环境；远程生产环境不在本版本本轮部署范围。

## [v0.3.0-rc.3] - 2026-11-03

### 新增

- 增加固定 Office 视觉门禁：20 份 Word/Excel/PPT 样本、真实隔离渲染、缩略图联系表和人工检查。
- 增加真实 DeepSeek 20+5 RC 门禁：合成任务与业务事实任务统一记录工具、成果、Token 和失败原因。
- 增加双客户端同步、Keycloak OIDC、15 分钟持续运行和故障恢复验收入口。

### 修复

- 修复非网络写入/隔离执行跳过持久授权登记，导致保存成果和 Office 生成被发布闸门拒绝的问题。
- 修复服务端派生 risk 字段造成合法授权摘要不一致的问题。
- 修复后续轮次无法列出和更新本任务现有成果的问题。
- 修复后台自动记忆保存可能在活动任务期间改变 epoch、导致任务中止的问题。
- 修复十轮记忆分析来源 SQL 的参数类型错误。
- 修复 schema v70 升级测试、故障恢复测试和数据库角色夹具漂移。

### 验证

- 常规评测全部通过；PostgreSQL 843/843。
- 20 份 Office 视觉样本通过；真实模型 20+5 全部通过。
- 双客户端、OIDC、容器冷杀恢复和 901 秒稳定运行通过。
- 本地与正式服务器已升级到 `v0.3.0-rc.3`；生产公网首页、管理页、健康接口和容器检查通过。

### 文档

- 增加 HTTP/SSE 接口总览，覆盖认证、工作区、任务运行、持久交互、文件预览、知识、记忆、业务事实、Skill/专家、自动化、后台和浏览器接口。
- 产品总纲升级到 v1.1，同步 RC.3 技术门禁、已部署能力、外部验收条件和多端接口原则。

### 修复

- 修复 Chrome PDF 预览拦截；自动化改用真实 PDF 验证阅读器内容，而非只检查 iframe 是否存在。

## [v0.3.0-rc.2] - 2026-11-03

### 新增

- 右侧栏升级为“预览 / 文件 / 浏览器”统一工作区，支持任务级页签和当前版本恢复。
- PDF、图片、Markdown、文本、HTML、CSV 在线预览；DOCX/XLSX/PPTX 通过隔离执行器转 PDF 只读预览。
- 共享浏览器隐藏时使用轻量状态探测，避免后台持续拉取截图；Agent 打开网页时自动切换。
- 服务重启后恢复遗留在已完成任务上的后续请求队列。

### 修复

- 修复成果核验只看最后一条回复，导致早停追问后漏检“声称生成但未写盘”的问题。
- 修复客户端构建测试依赖宿主 `PATH` 的问题。
- 减少 UI 高频轮询和轻量读取的审计写放大；业务事实与自动化列表热点完成索引/查询优化。

### 变更

- PRD 权限口径统一为确认/自动两档；系统总览与项目状态更新到 schema v70。
- 文件预览状态从“只有下载”调整为“基础预览已实现，Office 视觉 POC 继续”。
- 本地与正式服务器已部署；生产首页、管理页、健康接口、浏览器、Worker 和 Tunnel 烟测通过。
