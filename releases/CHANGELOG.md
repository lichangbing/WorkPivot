## [v0.3.0-rc.8] - 2026-11-05

### 新增

- Web 检测服务端版本变化并显示非阻塞刷新提示；Android 和 Windows 从只读更新清单发现新版本。
- Android 1.11 支持前台恢复检查、HTTPS 断点续传、200 MB 上限、SHA-256、包名、versionCode 和签名一致性校验，最终由系统安装器确认。
- Windows RC.8 支持启动/唤醒/手动更新检查，下载 ZIP/EXE 后执行大小和 SHA-256 校验并打开已验真制品。
- 新增 `/api/client-updates`、共享清单校验器、8 项客户端更新契约测试和发布清单生成脚本；可通过配置即时暂停分发。
- 新增 RC.8 真实业务验收脚本，使用真实 DeepSeek、Worker 和 Office 生成 DOCX、XLSX、PPTX、PDF 与 Markdown 成果。

### 修复

- Android 切换网络后按持久水位立即重连，正常 SSE 换流不弹错，局部轮询失败不再重复覆盖全局恢复提示。
- 401 去重退出、任务游标 409 重新取快照，待确认消息复用原请求标识，避免重连后重复提交。
- 修复普通 HTTP IP 访问下消息和附件发送被 `crypto.randomUUID()` 阻断。
- 修复空读取范围阻断记忆提取和十轮分析的问题。
- 修复数据库模式公开自助注册未受管理员策略控制的问题。
- 修复右侧工作区 PDF iframe 被 Chrome 拦截的问题。

### 客户端

- Android `1.11` / versionCode `12`，SHA-256：`bf90c325c077275d0cd3d8686a43f88c32c3a2e1f330d063bcf978560161ee6f`。
- Windows `0.3.0-rc.8` 便携包，SHA-256：`41c79f54152ca634e3457bc27191fae4a80620e7f3fa8d290c8ec2d0ae7f76c6`。
- HONOR Android 16 真机安装、Wi-Fi/蜂窝切换和断网草稿保留通过。

### 验证

- 全量 44 个套件、693 项断言通过；PostgreSQL 867/867；TypeScript、ESLint、依赖边界和文档链接通过。
- Office 生成 22/22、修改转换 16/16、固定视觉样本 20/20 通过。
- 五项真实业务验收 5/5 通过；输入 Token 4,143,611、输出 Token 156,655。
- RC.8 隔离短稳运行 602 秒、81 轮，每轮 17 项检查，内存和 PID 有界。

### 已知限制

- RC.8 真实模型/Browser/Worker/Office 混合 24 小时负载尚未完成，不能替代正式版长稳门禁。
- HONOR 系统拒绝 release 包降级到 versionCode 10，1.9 → 1.11 覆盖升级待另一台仍安装 1.9 的设备或下一版本自然升级验证。
- Windows RC.8 已校验下载链路，但尚未在 Windows 目标机执行实际替换和回滚验收。
- 不创建 `v0.3.0` 正式标签，直到上述门禁、可追溯发布提交和部署复核全部关闭。

## [v0.3.0-rc.7] - 2026-11-05

### 修复

- Android 切换网络后，工作区与任务 SSE 使用带抖动的指数退避重连，网络恢复和回到前台时立即按持久水位重连。

- APK SHA-256：`59248ed4e5f6f4ad5419dce918dac22988b76257fdcf6cc5e5b57d779c7c70d9`。

- 本地与正式服务器均部署 schema v72 和 RC.6；正式服务器保留旧镜像与联合备份。
- 新增 RC.6 发布门禁和本地/远程部署记录。

- 第二物理设备、24 小时真实负载和真实业务样本仍未验收。

## [v0.3.0-rc.5] - 2026-11-04

### 新增

- Web 与移动端可在任务运行中增加尚未授权的文件版本和记忆层，变更在下一个安全检查点应用。
- `GET /api/tasks/:id/resource-scope` 返回当前活动运行；新增 `POST /api/tasks/:id/scope-changes` 受控增量接口和 `scope_changed` 事件。
- schema v72 新增 `workpivot.run_scope_changes`，保存请求、前后范围快照、变更代次和审计时间。

### 变更

- 运行中范围只增不减；换版、删除文件、关闭记忆层和启用专家仍需新运行。
- 范围扩展在同一事务撤销旧计划、待处理交互和待消费审批，并生成强制相关的安全点消息。
- 工具闭包只能从审计记录中的前一代同步到下一代，不能跳过中间代次借新记录升级。

### 修复

- 修复运行中新增文件首次通过工具校验时仍被旧闭包拒绝的问题。
- 修复重复范围请求对“原范围已包含该记忆层”的误判。
- 修复运行中范围扩展后旧已批准动作仍可能被消费的问题。

### 验证

- PostgreSQL 861/861；全量 41 个套件、675 项断言通过。
- TypeScript、ESLint、Web/移动端生产构建通过；UI 验证增量选择、幂等提交和安全点提示。

### 文档

- 新增 RC 发布门禁记录，明确技术门禁、外部设备/IdP 条件和未完成的长稳要求。
- 新增加权 HTTP/SSE 接口总览，统一鉴权、幂等键、revision 乐观锁、资源范围、事件类型和错误恢复口径。
- README、项目介绍、PRD、系统总览、数据架构与项目状态统一到 `v0.3.0-rc.3` / schema v70；历史部署记录保留原时点信息。
