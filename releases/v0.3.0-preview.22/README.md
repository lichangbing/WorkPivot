# WorkPivot 0.3.0-preview.22

2026-09-11：MCP HTTP 接入与后台管理，已部署本机 WSL。

## 使用

打开 http://127.0.0.1:39880/admin.html，进入左侧「MCP 管理」。添加名称、后台可访问的 MCP 地址和可选 Bearer 令牌，保存后测试连接、查看工具清单并启用。启用的工具会进入当前账号下一轮任务的工具列表。调用前显示服务、工具和发送参数，确认后由后台调用，结果交回模型生成回复。

支持编辑、删除、启停及测试失败提示。配置与工具按账号隔离，其他管理员无法查看；配置入口仅管理员可用。生产凭据使用现有服务密钥加密存储，接口不回传令牌。更换地址不会沿用原凭据。编辑、重新测试后须重新启用。

## 范围

- Streamable HTTP；支持协商 2025-11-25、2025-06-18、2025-03-26 协议版本，JSON/SSE 响应、会话及分页工具发现。
- 本版不包含 stdio、本地进程启动、旧式独立 SSE 传输、OAuth、资源/提示词目录、二进制产物导入和断线续传。
- 每账号20个连接，单服务64个工具，总启用128个工具；单次响应2MiB，调用30秒超时。
- 外部调用逐次授权，只读模式拒绝。断线不自动重试；停止/禁用会取消客户端等待并尽力通知远端，无法保证撤销已经执行的远端操作。
- 容器内127.0.0.1指向容器自身，需填写容器可达地址。未配置真实第三方服务，本次使用本地模拟 MCP 和模型完成集成验证。

协议依据：[传输](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[生命周期](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle)、[工具](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。
