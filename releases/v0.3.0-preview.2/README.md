# v0.3.0-preview.2：独立后台客户端

安装 installers/WorkPivot-Setup-0.3.0-preview.2.exe。默认连接 http://192.168.1.158:39800；可通过“服务器 → 更换服务器”修改。

客户端不启动本地后台、不携带模型密钥及任务执行环境。账户、项目和大模型配置统一由服务器管理。首次使用需要注册管理员，初始化凭据见 releases/deploy/artifacts/first-login-192.168.1.158.txt；随后访问 /admin 配置模型。该凭据文件不随安装包分发。

原单机版的数据没有自动迁移。客户端不可达服务器时显示连接页面，不启动本地替代服务。当前服务器沿用不挂载Docker socket的部署设置，命令沙箱未启用；目前仅内网HTTP，不是公网RC发布。

验证：客户端13项检查、类型/Lint/依赖检查通过；打包态真实连接192.168.1.158成功（exit0），离线提示测试通过（预期exit2），两者均未创建本地后台数据目录。安装包校验值见 installers/SHA256SUMS.txt。
