# WorkPivot 0.3.0-preview.1

日期：2026-09-08。内部体验预览版，基于当前工作区代码构建，尚未达到 M5 RC 发布门槛；不创建正式发布 tag。

## 本版可体验

- 授权请求绑定用户和任务，拒绝错配与非法审批。
- 一次性授权仅生效一次；会话和永久路径授权按用户、任务及读写模式隔离。
- 管理后台新增「路径授权」，可查看与撤销永久授权。
- 文件/命令授权等待支持停止、断线清理及 120 秒超时。

## 安装与升级

安装包：`installers/WorkPivot-Setup-0.3.0-preview.1.exe`（Windows x64）。校验值见 `SHA256SUMS.txt`。

此包沿用 WorkPivot 的应用标识与默认数据目录；安装可能替换现有 WorkPivot。先退出应用并备份应用数据根（默认 `%USERPROFILE%\.workpivot`）及工作区（默认 `%USERPROFILE%\WorkPivot\workspace`）；如配置了 WORKPIVOT_HOME/WORKPIVOT_WORKSPACE，应备份对应路径。

旧版全局白名单没有用户和任务归属，升级后失效，需要重新确认。保存新授权时旧配置保留一代 `.bak`。

如只想启动体验，可运行 `installers/win-unpacked/WorkPivot.exe`；它同样默认使用现有数据目录，不是数据隔离的便携版。

## 验证与限制

当前代码通过 11 个模拟评测套件共 255 项断言、类型/Lint/依赖/许可检查；授权管理页面的列表与撤销已验证。此版本仍有文件与命令隔离、账户会话过期、生产密钥保护和数据恢复等 RC 待办，适合内部体验。

本次 NSIS 安装包构建成功；对应打包目录中的程序在独立临时业务和 Electron 配置目录下启动验证通过（SMOKE OK，退出码 0，页面累计 584ms）。未执行覆盖安装测试。安装包未做代码签名。
