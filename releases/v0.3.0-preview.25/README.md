# WorkPivot 0.3.0-preview.25

仅保留确认模式（ask）与自动模式（auto），默认自动模式。输入区和设置页均显示两个选项及说明。

- 确认模式：界内读取自动执行，写入和命令执行逐次确认。
- 自动模式：界内常规文件操作和隔离命令自动执行，已识别的高风险命令仍逐次确认。文件策略、账号隔离与Worker隔离不因模式放开。
- MCP仍逐次确认，本轮没有将任何已有MCP设为免确认。单工具只读免确认配置后续另行实现。
- 旧readonly读取为ask，旧workdir读取为auto，旧auto保持auto；兼容读取不批量改写用户存储。新设置接口仅接受ask/auto（个人设置另可null恢复默认）。
- 不额外重做安装包；preview.24客户端直接加载后台的新页面。

验证：类型检查和Lint通过。W33新版两模式32项、W31 39项、W28 18项在Windows通过；Linux另加W26 61项，共150项通过。部署前备份，WSL更新preview.25。
