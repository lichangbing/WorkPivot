# WorkPivot 0.3.0-preview.14

登录只填写用户名和密码。业务空间改为按账号隔离，管理员和成员遵循相同的数据可见性规则。

- 每个账号拥有独立项目、任务、文件、个人/项目记忆、审计、回收站、定时任务和运行状态。
- 管理员可以管理账号及部署级模型配置，但不能查看、修改、转移其他账号的项目和任务；个人项目不再支持成员分配。
- 普通用户可以创建自己的项目并切换个人记忆开关。
- 登录、设置和后台移除租户标识与租户管理入口；旧命名空间仅作为内部兼容身份注册表保留。用户名全局唯一，旧重复用户名拒绝歧义登录。
- 请求由已认证账号确定空间，忽略客户端的租户选择；文件授权不能扩大个人工作区。命令执行仅允许隔离 Worker，个人空间不回退宿主执行。
- 模型配置仍为部署配置，所有账号可以使用管理员配置的模型；不会向客户端返回模型密钥。
- 包含 preview.13 附件列表去重修复。

迁移使用复制方式，不删除旧数据。明确归属的任务、项目和个人记忆迁入各自空间；无主数据及跨账号共用目录保留原件，不自动分配。共用旧目录中的文件需部署管理员在确认所有者后离线恢复到对应个人空间。旧密码及会话保留。

当前 WSL 已由 preview.12 备份后更新到 preview.14，健康检查通过。2 个账号各自 1 条任务，所有归属校验通过；旧的 2 条任务原始记录及共用文件保留。共用文件归属待用户确认。

验证：Windows W26 60/60、无网络无挂载 Linux 容器 W26 61/61（含符号链接越界）；类型检查、Lint、前端构建、依赖边界通过。本次未重跑旧 511 项全量基线；旧 W25 组织共享权限语义已由 W26 个人空间专项替代。

回退：启用新版并产生个人数据后，不能只切回旧镜像，应使用升级前备份并单独保全升级后的个人数据。应用管理员隔离不等同于对宿主机/数据库系统管理员加密隔离。
