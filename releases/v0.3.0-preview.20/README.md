# WorkPivot 0.3.0-preview.20

Skill 文件树支持文件夹高亮选择、独立箭头展开/折叠、全部展开/折叠及根目录选择。图标使用现有 SVG 系统，随主题变色。

选中文件夹后，新建文件、文件夹、脚本以及上传默认定位该目录；选择文件时默认定位其父目录。新建位置有文字提示。选择或折叠文件夹不会丢弃右侧未保存内容，切换文件仍提示未保存修改。打开新建文件时自动展开父目录。

验证：类型检查、Lint、Web 镜像构建通过。独立测试账号页面验证目录选中、子文件折叠隐藏与展开恢复、未保存编辑保留、脚本默认创建路径。

WSL 已备份升级 preview.20，健康检查通过。刷新后台即可使用，桌面无需重新安装。
