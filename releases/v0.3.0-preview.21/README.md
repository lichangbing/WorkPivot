# WorkPivot 0.3.0-preview.21

Skill 包编辑器移除全部展开/折叠、根目录、新建位置、上传路径、单独的新建脚本、导出草稿、校验草稿和恢复草稿入口。

同一行使用 SVG 图标提供新建文件、新建文件夹、上传文件、ZIP 导入、删除选中项及发布；保留悬浮提示和无障碍标签。脚本统一通过新建文件填写 .sh/.py/.js 等扩展名创建。选择目录确定创建和上传位置，点击文件树空白处取消选择并回到顶层位置。发布时自动校验。

删除支持选中的文件或整个目录及其后代，仅修改当前草稿，保留发布版本；根目录和主说明不能删除。界面删除前显示确认。

验证：类型检查、Lint、Web 镜像构建通过；W30 Windows/Linux 各51项通过。独立测试账号界面验收图标工具栏、移除的控件、目录选中后的删除状态及新建路径。

WSL 已备份升级 preview.21，健康检查通过。桌面客户端无需更新，刷新后台即可。
