# preview.28 三层记忆与角色默认模板

右侧「技能与 MCP」下增加任务、项目、个人记忆入口，可查看、编辑和保存。任务记忆仅用于当前任务；项目记忆用于本项目任务；个人记忆用于本账号任务。原有个人条目保留，可查看与删除。

开启自动加载后，每次发起任务消息都会读取相应记忆，并补充所选角色模板。用户可选择后台默认、指定角色或不使用角色。后台「默认记忆」支持新增、修改、停用、删除和指定默认模板，预置研究员、项目负责人、财务。初始不指定默认角色，避免自动改变已有账号的角色。公共模板与私有记忆分别存储，管理员不能借此读取其他账号的记忆。

修改从下一轮生效，不追溯清除已进入模型的上下文。关闭自动加载保留已保存内容，停止记忆工具写入并取消本账号尚未确认的长期记忆写入。当前提供自动加载与手动维护，不包含任务结束后自动摘要。

保存检查版本，避免多个窗口覆盖修改；冲突后可重新加载。手写记忆与每个模板限制 20000 字符，最多 50 个角色模板。

验证：类型检查、lint、前端构建通过；Windows W35 41 项、W5 12 项；隔离 Linux W35 41 项、W5 12 项、W26 61 项通过。模拟模型验证实际注入内容，未调用付费模型。Linux 测试未挂载 Docker socket。

服务镜像：`workpivot-server:0.3.0-preview.28`。沿用 preview.24 桌面客户端，界面由后台提供，刷新即可加载。
