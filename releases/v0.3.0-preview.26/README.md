# WorkPivot 0.3.0-preview.26

客户端技能市场改为应用内弹窗，不再跳转后台。支持搜索名称/描述、查看技能说明，选择加载后在当前任务输入框添加 `/技能名`，发送时通过已有斜杠激活流程注入技能说明和开放资源。

无任务或任务正在本客户端执行时不能加载，仍可浏览。普通成员可读取市场，不获得后台管理权限。列表仅返回名称、说明、来源与发布版本，不返回服务器路径或草稿正文。

发布范围暂沿用当前账号隔离规则：展示内置技能与当前账号可用的已发布技能包；隐藏草稿、未发布包和停用技能。跨账号公开发布尚未实施，未自动公开已有私有技能。已询问用户是否需要所有用户共享管理员公开发布的技能，后续按其选择扩展。

类型与Lint检查通过；W30技能包/市场56项、W20技能加载16项通过。发布后台preview.26，客户端无需重装，刷新即可。
