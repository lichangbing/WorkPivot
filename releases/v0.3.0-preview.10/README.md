# 本机目录选择 · preview.10

新建项目的工作目录改为点击打开系统文件夹选择窗口，取消选择保留原值。需安装此版 Windows 客户端；普通浏览器和旧客户端会提示升级，不会模拟本机路径。

当前 WSL 后台已更新，尚未配置用户本机目录挂载。选定目录要能实际工作，部署时需把用户指定的 Windows 目录经 WSL 路径挂载到 /data/workspace 下的专用子目录，并设置 WORKPIVOT_CLIENT_DIRECTORIES 为 JSON 数组，例如 `[{"client":"E:\\资料","server":"/data/workspace/local-documents"}]`。仅声明映射不会自动挂载目录；不得通过挂载整个磁盘或 Docker socket 代替指定目录挂载。

服务器拒绝未配置目录、越界路径、符号链接逃逸和不可用目录。项目保存服务器可访问的映射路径；账户、模型调用与任务执行仍在后台。

验证：类型检查、Lint、前端/桌面构建；W16 客户端 13 项检查、Linux W24 目录映射 11 项检查通过。实际用户目录读写验收待提供路径并挂载后完成。
