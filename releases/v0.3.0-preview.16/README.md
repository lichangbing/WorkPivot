# WorkPivot 0.3.0-preview.16

任务监控与产物流程更新：

- 任务区分排队、执行、等待授权、失败、停止和完成；支持取消排队、停止、重试和继续。并发额度按账号隔离，服务重启后恢复中断标记。
- 切换任务不会混入其他任务的实时回复，输入草稿和附件按任务保留；重新进入任务可恢复待处理授权卡片。
- 产物显示生成中、可用或失败状态，支持下载、用本地默认软件打开、显示所在目录，以及查看和下载历史版本。版本快照在每轮结束时保存，同内容同状态不重复保存。
- 任务完成显示绿色标记和删除线；失败或停止不会误标为完成。

安装包：installers/WorkPivot-Setup-0.3.0-preview.16.exe。校验文件：SHA256SUMS。

WSL 服务已备份后升级，地址 http://127.0.0.1:39880，健康检查返回 preview.16。没有挂载 Docker socket。

验证：类型检查、Lint、前端和桌面构建通过；Windows W26/W27/W28 为 60/25/18 项，Linux 为 61/25/18 项，全部通过。浏览器模拟连续回复期间切换任务，验证内容隔离、完整回复保留和独立草稿恢复。打包客户端独立配置启动退出码 0。

限制：本地打开使用下载副本，不自动回写后台；50MB 以上文件不保存历史快照，历史版本暂不自动清理。真实 Office 软件界面未自动验证。MCP 接入及 Excel/PPT/Word 专项技能仍留待后续。旧共享目录文件归属仍待确认，未擅自分配。
