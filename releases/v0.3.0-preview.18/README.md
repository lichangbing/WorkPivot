# WorkPivot 0.3.0-preview.18

后台 Skill 管理升级为文件包管理，继续使用左侧导航和浅色/深色主题。

## 使用

1. 打开后台的 Skill 管理，选择现有技能，或填写英文名称新建技能包。
2. 文件树中可编辑 SKILL.md、脚本、参考资料和其他 UTF-8 文本。填写相对路径可新建文本或上传资源；上传同路径文件可替换草稿资源。
3. ZIP 导入替换当前包的全部草稿文件，支持根目录 SKILL.md 或单层技能目录。包内 name 必须与当前技能包名称一致。新导入技能可以先新建同名包再导入。
4. 保存草稿不会影响已发布版本。点击校验草稿检查说明、JSON、Markdown 文件引用与依赖；点击发布生效提交整个包。
5. 发布历史支持下载整个旧版本和回退。回退只切换发布版本，不丢弃草稿；恢复草稿则用当前发布版替换草稿。

图片资源支持 PNG/JPEG/WebP/GIF 预览。Word/Excel/PPT 等二进制模板可以上传、替换、下载，使用本地软件查看，不在网页中编辑 Office 内容。

## 依赖与运行

可添加 skill.json，声明 requiredSkills 和 runtimeDependencies 字符串数组。发布校验依赖技能是否可用；运行依赖仅记录，不自动安装，依赖技能不会因此自动成为独立智能体。脚本上传和发布不会执行代码，仍使用现有任务权限及隔离执行服务。

技能包按账号保存，不改变其他账号数据。已有内置/个人技能首次打开时保留完整资源和已有说明覆盖，建立初始版本；之后主说明旧接口不能绕过草稿发布。项目目录技能保持原发现优先级，管理器不直接改写项目文件；需作为独立命名包导入管理。

每轮任务固定其已发现的发布版本，后续发布和回退不会混用该轮的脚本、模板、说明；禁用仍阻止后续加载。已经注入模型上下文的内容不会被追溯删除。

## 限制与持久化

- 最多256个文件、512个目录条目、8层路径，单文件8MiB、整包16MiB。
- 文本编辑与模型按需读取上限256KiB，UTF-8 编码。SKILL.md 顶部沿用当前 name/description 单行元数据格式。
- ZIP 在写入草稿前检查路径、重复名、链接、解压大小、校验和，解压失败不会改变现有草稿。
- 发布文件保存在独立版本目录，完成写入后原子切换指针；旧版本暂不自动清理。草稿冲突通过版本号拒绝覆盖。
