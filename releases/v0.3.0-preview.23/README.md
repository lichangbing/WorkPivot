# WorkPivot 0.3.0-preview.23

2026-09-11，已部署本机 WSL，健康检查通过。

- MCP 管理可逐个启停工具，开关按账号隔离，重新测试保留禁用设置。模型目录和右侧工具清单使用相同可用性规则。
- 工具设置变更会撤销该服务当前进行中的调用，旧工具引用不能继续执行；新清单在下一轮生效。取消等待不保证撤销远端已执行的操作。
- 任务显示服务名 / 工具名、等待授权、执行中、成功、失败、拒绝和停止。执行耗时不含授权等待；连接中断且未收到结果时显示状态待确认。
- 调用与结果按调用 ID 关联，转写保存友好名称、状态和耗时。MCP 结果预览上限8000字符。
- 右侧可展开查看工具名称与可用状态；后台管理保持黑白主题兼容。

验证：类型检查、Lint、前端构建通过。Windows W31 39项通过；Linux发布镜像 W31 39、W28 18、W19 6，共63项通过。临时账号浏览器验证工具展开、禁用、状态变化及其余工具保持可用。
