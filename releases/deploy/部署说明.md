# WorkPivot 企业版部署说明（v0.2.0，J02 拓扑二）

> 形态：WorkPivot 服务端集中部署在企业内网一台服务器上，员工用**浏览器**访问（zero-install，无需安装桌面端）。
> 多用户：管理员分配账户；任务归创建人私有，管理员可见全部；项目为团队共享（管理员创建）。

## 环境要求

| 项 | 要求 |
|----|------|
| 服务器 | Linux x64（Docker），2C4G 起步；建议 4C8G（多用户并行） |
| 软件 | Docker + Docker Compose |
| 网络 | 内网开放 39800 端口；服务器可访问模型 API（DeepSeek 公网 / 内网 Ollama） |

## 首次部署

```bash
# 1. 上传代码到服务器（或 git clone）
cd WorkPivot
docker compose up -d --build

# 2. 查看日志
docker compose logs -f workpivot

# 3. 浏览器访问（首次注册的账户自动成为管理员）
http://<服务器IP>:39800
```

首次启动即初始化：注册管理员 → 管理后台（页面右上角 ⚙ → 前往后台，或直接访问 `/admin`）配置模型供应商 → 建项目 → 给员工开账户（后台用户管理）→ 员工登录使用。

## 数据与备份

| 卷 | 内容 | 备份建议 |
|----|------|----------|
| `workpivot-data` | 账户/任务转写/记忆/审计/供应商密钥 | 每日备份（纯文件 JSONL，可直接 tar） |
| `workpivot-workspace` | 任务工作区与交付物（Word/PPT/Excel 真实文件） | 每日备份 |

```bash
docker run --rm -v workpivot-data:/data -v $(pwd):/backup alpine \
  tar czf /backup/workpivot-data-$(date +%F).tgz -C /data .
```

## 环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `WORKPIVOT_PORT` | 39800 | 服务端口 |
| `WORKPIVOT_HOST` | 0.0.0.0（镜像内已设） | 监听地址，保持 0.0.0.0 |
| `WORKPIVOT_MAX_PARALLEL` | 8（compose 内 16） | 同时运行的 agent 任务上限 |
| `WORKPIVOT_HOME` | /data/workpivot | 应用数据根 |
| `WORKPIVOT_WORKSPACE` | /data/workspace | 工作区根（任务真实文件） |

## 升级

```bash
git pull
docker compose up -d --build   # 数据在卷中，不受影响
```

## 安全注意事项（内网部署）

- 当前版本为**内网 HTTP** 明文传输，请勿直接暴露公网；需要外网访问时置于 VPN 或反向代理（HTTPS）之后
- 供应商 API Key 经 OS 级加密（容器内回退 base64）——务必限制服务器登录权限
- 首个注册用户即管理员：部署完成后立即注册并改密，避免端口暴露窗口期被抢注
- 审计日志（按天 JSONL）在 `workpivot-data` 卷的 `audit/` 目录，后台可查看/导出
