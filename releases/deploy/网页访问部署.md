# 网页访问部署与使用

适用于 PostgreSQL 运行链路。WebFetch 直接由后端提供；动态页面使用独立浏览器服务。没有第三方搜索/浏览器 API 账号要求，不需要购买搜索接口。模型分析仍消耗已配置模型的用量。

最新本机部署及共享浏览器界面见[2026-10-17上线记录](网页浏览器上线-20261017.md)。下文为通用部署说明；普通对话现已共享右侧浏览器，自动化仍使用一次性上下文。

## WebFetch

更新代码、安装锁定依赖并重启后端后，对话可调用 `web_fetch`。例如：“读取 https://example.com ，说明网页内容并附上来源。”首次调用走现有外部工具确认，拒绝后不会访问目标；隔离执行的自动模式不会自动批准网页访问。

只支持公网 HTTP/HTTPS 标准端口，不支持登录、私网、文件下载或任意请求头。响应上限2MiB，正文返回最多24000字符并标记截断，链接最多40条、单条URL最多1024字符，标题最多500字符。网页内容是参考资料，不是系统指令。网页页面中的指令不能扩大执行权限。

## 独立浏览器服务

1. 在受保护环境文件中生成独立的 `WORKPIVOT_BROWSER_TOKEN`，至少32位且不含空白，服务端与浏览器服务使用相同值，不提交真实值。
2. 从仓库根目录执行 `docker compose --env-file <受保护环境文件> -f releases/deploy/compose.browser.yml up -d --build`。
3. 给 PostgreSQL 后端配置 `WORKPIVOT_BROWSER_URL=http://127.0.0.1:39991` 和相同令牌，再重启后端。若后端运行于容器，127.0.0.1 指向容器自身，须将两者接入同一个受控网络，通过 `http://browser:39991` 访问，并移除不需要的宿主端口发布；不能直接使用本机地址。
4. 在对话中请求“打开某公开网页，点击指定按钮、滚动并保存截图”。核对授权卡中的 URL 和步骤，再确认。截图作为 PNG 任务成果出现，可沿现有成果接口下载。

浏览器采用 Playwright 1.64.1，与 `Dockerfile.browser` 中官方镜像版本保持一致。使用非 root 用户、Chromium 沙箱、固定官方 seccomp、只读根目录、临时可写目录及资源限制，不挂载业务文件、数据库凭据或 Docker socket。宿主需支持非特权 user namespace；若宿主禁止，不应关闭沙箱绕过，应调整受控宿主策略或使用支持该能力的独立宿主。

`browser-seccomp.json` 来源为 Playwright v1.64.1 的 `utils/docker/seccomp_profile.json`，补充允许Chromium在自身用户命名空间内建立chroot沙箱的规则（容器仍不授予宿主SYS_CHROOT），配套 LICENSE/NOTICE 为 Apache-2.0。来源：https://github.com/microsoft/playwright/blob/v1.64.1/utils/docker/seccomp_profile.json 。升级浏览器须同步依赖、锁文件、镜像、seccomp及复验。

临时浏览任务一次最多2个，自动化每次使用全新上下文，最多10步点击/滚动/等待，总时限45秒，结束清除上下文。普通对话与右侧浏览器共享页面，最多4个共享会话，10分钟无操作回收，视口随面板调整。截图仅为当前视口，不是整页。不支持持久登录、表单提交、任意JS、文件下载和上传。浏览器通过安全HTTP层获取资源，禁止非GET、WebSocket、Service Worker；不兼容依赖这些能力的网站时须明确报告，不能宣称已完整读取。

本机开发可在 `code` 下执行 `node --import tsx scripts/browser-worker.mts`，默认监听127.0.0.1:39991；需先安装匹配的 Chromium 和系统依赖。生产建议使用独立容器。健康端点只说明服务进程可访问，不代替实际网页访问验收。

## 定时任务

自动化编辑页“允许访问的网页来源”每行填写一个完整 origin，如 `https://example.com`，不含路径。重定向目标及浏览器CDN子资源也须在列表内。配置最多20项；来源范围属于用户确认的计划快照，修改后必须重新确认。

留空的旧计划没有网页工具，不会因本次升级自动获得联网权限。输入要求、Skill 和来源确认后，计划可通过网页工具采集、交给模型分析，用 `save_artifact` 保存文本/JSON成果，或保存浏览器截图。脚本沙箱仍无网络；不支持脚本任意下载或联网安装依赖。本次没有新增结构化采集库和展示中心。

计划仍沿用现有执行服务依赖，需配置 Skill worker 才能启用。网页失败或撤销后不发布该运行的暂存成果。

## 网络与排查

- DNS 返回私网、环回、保留地址会被拒绝，重定向每跳重新检查并固定已校验地址连接。Fake-IP 代理常返回198.18.0.0/15或ULA IPv6，本功能会按保留地址拒绝；可为运行服务配置正常DNS/代理排除规则，或由管理员显式配置WORKPIVOT_WEB_DOH_URL为可信HTTPS JSON DoH端点。后者只发送域名，仍对解析结果执行公网校验及固定连接；不能放开整个保留地址段。
- 动态页面使用浏览器工具；HTTP 401/403、验证码、登录限制需要人工处理，不能伪报读取成功。
- 浏览器来源白名单缺少CDN时页面可能不完整，结果包含被阻止请求数；核对必需域名后修改计划并重新确认。
- 取消或超时会结束浏览器上下文；不自动重放有结果不明的点击。

## 验收入口

在 `code` 下执行：

- `pnpm eval:web`：离线正文提取、编码、URL/IP/DNS/重定向和工具授权边界。
- `pnpm eval:web-browser`：真实 Chromium 渲染、交互、截图、隔离、取消及服务协议；默认测试浏览器 `/usr/bin/google-chrome`，可用 `WORKPIVOT_TEST_CHROME` 指定可执行文件。
- `pnpm eval:web-database`：独立临时 PostgreSQL，检查真实对话授权、自动化来源范围、结果发布及停止后的迟到拒绝；不使用业务卷。
- `node --import tsx eval/web-tools.mts --live`：真实公网读取及大小限制。仅测试可用 `WORKPIVOT_TEST_DOH=1` 从 Cloudflare DoH 获取实际公网地址，仍执行IP校验和固定连接；生产不启用此测试解析器。

本次开发的实际验证结果见[实现记录](../../docs/02-design/architecture/archive/capabilities/网页读取与浏览器访问.md)。部署须另行授权；切回旧版本前停用带网页访问的计划，移除后端浏览器配置并停止浏览器容器即可，无数据库结构迁移。
