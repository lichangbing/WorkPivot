# WorkPivot 0.3.0-preview.17

后台菜单改为左侧导航，保留浅色/深色主题切换。

Skill 管理支持点击技能打开 Markdown 说明编辑器，编辑、保存、取消、启用和停用。名称保持不变，描述和正文可修改。接口校验格式、正文、大小和版本，冲突保存返回明确提示。修改按当前账号保存，保留源技能脚本和资源目录；不更改其他账号。模型后续 load_skill 会读取修改后的说明，已加载到对话中的旧内容不会追溯删除。

本轮编辑范围为技能说明 SKILL.md；脚本、二进制模板和资源文件编辑不在本轮范围。管理列表沿用当前账号内置、个人和工作区根目录的技能发现范围，不遍历其他项目。

验证：类型检查、Lint、Web 构建通过；Windows W29 19 项、W20 16 项通过；Linux W29/W20/W26 共 96 项通过。浏览器模拟数据验收左侧菜单、点击编辑、保存、重新打开、停用与黑白主题。

WSL 已备份后升级 preview.17，健康检查通过。现有 preview.16 桌面客户端继续使用，刷新后台即可，无需新安装包。
