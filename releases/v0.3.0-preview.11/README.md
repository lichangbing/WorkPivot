# 租户隔离 · preview.11

已部署至本机 WSL，服务地址 http://127.0.0.1:39880。现有桌面客户端刷新即可加载，无需为本次租户功能重新安装。

## 使用

- 原账号属于 `default` 租户；原首个管理员可在管理后台的“租户管理”创建租户及其首个管理员。
- 新租户登录时填写租户标识、用户名和密码。相同用户名可在不同租户分别使用。
- 租户管理员只能管理本租户的用户、项目、任务、配置和审计。平台管理入口只展示租户信息并允许创建，不自动授予其他租户业务数据访问权。
- 新租户需要单独配置模型。默认项目仅在其所属租户内共享；普通项目仍按负责人和成员名单控制访问。

## 隔离实现

令牌绑定租户，服务器验证后建立异步租户上下文；不接受业务请求指定其他租户。用户、项目、任务、配置、记忆、模板、Skill 设置、审计、回收站和定时任务按租户存储。审批与运行状态也分租户保存，异步流、上传和后台调度延续原租户上下文。

为兼容原路径，默认租户的数据与工作目录保留原位置；新租户数据位于 WORKPIVOT_HOME/tenants/<id>，工作目录位于 WORKPIVOT_WORKSPACE/.tenants/<id>。默认租户的文件工具和执行快照不能进入保留的 .tenants 目录；新租户不能越出自己的工作目录。

多租户命令执行仅使用已有 Worker 的受限文件快照，或关闭命令执行。不能使用直接宿主执行模式创建新租户；如果原项目或任务位于工作区外，须先调整目录再启用多租户。内置 Skill 为共享只读资源，各租户的私有 Skill 与配置独立。

本机目录挂载仍需按租户配置，不能把同一实际目录开放给互不信任的租户。默认租户使用 WORKPIVOT_CLIENT_DIRECTORIES；其他租户使用 WORKPIVOT_CLIENT_DIRECTORIES_<大写租户标识，连字符替换为下划线>，映射目标须位于本租户工作目录。

## 迁移与验证

更新前已备份数据和工作目录。迁移添加租户标识与明确的旧项目成员范围，保留原密码哈希、会话、路径、文件和模型密文；迁移可重复。实际部署核对：2 个账号、2 个项目、1 个任务均归入 default，1 个平台管理员。

完整回归 511 项通过，其中租户专项 44 项；专项还在 Linux 镜像中通过。覆盖跨租户接口访问、相同用户名、配置隔离、并发 SSE 与工具写入、上传上下文、审计、路径越界、审批状态、定时任务令牌以及旧账号和旧会话迁移。类型检查、Lint、构建和前端依赖检查通过；管理页面已做浏览器显示验证。

这是应用权限、存储目录和执行快照的隔离，共用后台进程与宿主。尚未提供独立租户虚拟机、租户删除/停用或独立资源计费。创建新租户后不要直接切回旧版服务读取现有卷；需使用更新前备份恢复，避免旧版忽略租户边界。
