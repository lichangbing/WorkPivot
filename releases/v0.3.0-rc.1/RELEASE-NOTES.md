# WorkPivot 0.3.0-rc.1

2026-09-16，单用户使用规模的服务端与网页候选版。PostgreSQL schema v25，独立执行 Worker 沿用 0.2.0。RC 不等同于正式生产验收，健康接口继续保留 `productionReady:false`。

## 本次交付

- 管理员在 `/admin` 发布、编辑、停用专家模板；用户在设置→专家创建私有副本，编辑角色、启动规则和关联 Skill。模板更新不覆盖私人副本，用户查看后主动采用。
- 任务选择专家，可将当前选择设为项目默认；默认只影响新任务。运行中禁止切换或删除关联专家。恢复读取上下文，不自动重复历史工具操作。
- 私有专家经验支持新增、修改、锁定、历史版本、删除和按关键词检索。默认加载最近十条，工具可继续检索。加载经验、自动整理分别控制。
- 已完成对话中的明确方法/纠错，由模型提出最多三条有原文证据的建议。支持新增、修改、合并，展示原经验，用户可编辑确认或拒绝；自动模式也不跳过确认。整理失败自动重试三次，并提供手动重试入口。
- 多端重复确认幂等；旧版本、失效来源及其他用户的操作被拒绝。删除来源任务、项目、资料或经验时，清除相关衍生经验正文与历史，旧上下文和迟到建议不能继续生效。
- 文件删除同时清除该来源任务派生的三层记忆正文及已确认建议中的内容/证据。当前采用保守失效，无法安全拆分的合并记忆整条失效。

既有项目/任务、聊天与附件、三层记忆确认、长上下文摘要确认、Skill/MCP、成果版本、用户隔离及当前任务 SSE 保留。

## 范围边界

向量 RAG/embedding、结构化指标库、文档处理增强按用户要求暂缓；多用户公平调度与扩缩为第二阶段，项目协作为第三阶段。经验转 Skill 为后续增强。专家仅整理用户明确提出的方法，不自动从工具结果归纳成功经验，也不自动赋予 Skill/MCP 权限。

本包为服务端/网页版本，不包含新 Windows/macOS 安装器。原薄客户端连接服务器后获取服务器页面；旧版客户端特有的自动成果同步不作为本次数据库网页版 RC 的验收范围。
