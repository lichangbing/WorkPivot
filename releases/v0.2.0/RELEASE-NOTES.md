# v0.2.0 发布说明（企业形态 · 拓扑二基础）

- **日期**：2026-09-07
- **类型**：minor 版本——企业服务端集中部署（J02 拓扑二 4a）

## 新增

- **服务端集中部署**：`WORKPIVOT_HOST=0.0.0.0` 对内网开放，员工浏览器直接访问（zero-install）；Docker 镜像 + docker-compose 编排 + 部署说明（`releases/deploy/部署说明.md`）
- **任务所有权隔离**：任务归创建人私有——成员仅能查看/操作自己的任务，管理员可见全部；跨账号访问 403；旧任务（无归属）仅管理员可见。项目保持团队共享（管理员创建、全员可见）
- **多用户并行可配**：`WORKPIVOT_MAX_PARALLEL`（服务端多用户同时跑 agent 任务）

## 升级（自 v0.1.x）

- 桌面端：覆盖安装即可（数据目录独立）
- 企业服务端：见 `releases/deploy/部署说明.md`（Docker 部署为本次新增能力）
- 注意：升级后历史任务（v0.1.x 创建、无归属信息）仅管理员可见；如需分配给成员，等待批次 4b 的任务移交功能
