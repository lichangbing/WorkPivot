## RC 门禁结果

- 20 份固定 Office 样本：8 DOCX、6 XLSX、6 PPTX；真实隔离执行器渲染、文本/页数断言和人工联系表检查通过。
- 真实 DeepSeek：20 个合成任务 + 5 个业务事实任务全部通过；覆盖文件读取、成果保存、PDF、Office 生成、记忆、网页、纠正、版本更新和跨项目隔离。
- 双客户端：两个独立登录会话、桌面与移动视口同时接收任务、用户消息和模型回复。
- 故障恢复：整 API 容器强制终止、两次重启、MCP 未知结果和安全 SSE 重放通过。
- 持续运行：901 秒、119 轮、每轮 17 项检查；内存和 PID 无持续增长。
- OIDC：Keycloak 协议实验 21 项和业务接入测试通过。
- 完整评测、PostgreSQL 843 项、许可、依赖、类型、Lint 和客户端构建通过。
- 本地与生产服务端镜像 ID：`sha256:a0bf4d5a6e5f151ec821a89e85bb362bb4305c103ad3d3984deddc91a3fe4a74`。

## 关键修复

- 非网络写入和隔离执行现在统一进入持久许可记录，修复“工具已调用但发布闸门找不到批准记录”。
- 权限比对剔除服务端派生的风险字段，修复合法批准被误判为“审批与实际调用不一致”。
- 后续轮次可列出本任务现有成果，并在成果版本进入读取范围后更新版本链。
- 自动记忆保存会避开活动任务，防止后台整理改写 epoch 并中止正在执行的请求。
- 修复周期记忆分析的 SQL 参数类型错误，恢复个人/项目十轮分析。
- 修复 schema v70 数据库升级测试和故障夹具的角色/目录漂移。

## 已知外部门禁

- 当前没有第二台物理 Android/桌面设备，双客户端门禁由两个独立登录会话和桌面/移动视口完成，不等同物理硬件验收。
- 当前没有目标企业 IdP；Keycloak 和业务 OIDC 链路通过，但供应商级登录、企业微信和组织同步仍需目标环境。
- 901 秒持续运行不替代 24 小时以上真实业务负载。

## 升级与回退

本次无数据库迁移。升级需重建 API 服务端；浏览器仅在有前端变化时重建。旧镜像可继续读取 v70 数据库。运行中的授权、记忆和成果数据不删除。
