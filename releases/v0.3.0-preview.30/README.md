# preview.30 成果浏览与本地同步

右侧「产物」标题旁的文件夹图标打开服务端文件浏览。已交付成果与其他生成文件分开显示；旧任务文件可手动标为成果或取消。产物侧栏只显示已交付成果的名称。

新任务通过 `deliver_files` 工具明确登记最终成果，成功结束后发布不可变文件快照。脚本、草稿、缓存及其他未交付过程材料不进入同步清单；失败任务不发布新成果。已登记文件在以后成功运行中更新版本。旧任务不按文件扩展名自动猜测成果，需要用户选择。

安装本目录的 preview.30 Windows 客户端，打开「产物 → 文件夹图标 → 选择同步目录」。选择一次后，登录运行期间约每 30 秒把当前账号所有任务的已交付成果单向同步至本机；后台关闭或客户端退出后暂停，下次登录自动补同步。可立即同步、暂停、更换目录或打开本地目录。

本地按服务器/账号隔离的子目录及任务 ID 保存，文件相对目录结构保留。相同版本不重复下载；本地修改不回传。服务器更新与本地修改冲突时保留本地文件，另存带「服务器」标记的副本。取消成果、服务端删除任务或文件不会删除已下载副本。

同步下载验证文件大小与 SHA-256，仅下载已成功交付快照；不下载过程目录。单文件最多 50MB，不支持 Windows 非法文件名。浏览器和旧客户端可查看成果清单、手动下载；自动同步必须更新客户端。
