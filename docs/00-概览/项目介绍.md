# WorkPivot 项目介绍

> 状态：✅ 当前产品一页纸
> 更新日期：2026-10-28
> 版本：`v0.3.0-rc.1` + 业务事实增量，schema v63

## 一句话

**WorkPivot 是面向真实办公交付的私有化 AI 工作台。** 用户用项目组织资料、用任务表达目标，AI 在明确权限内读取文件、调用工具并交付可追踪、可继续修改的 Office/PDF/报告成果。

## 为谁解决什么问题

主要用户是处理敏感材料和知识工作的内部团队，例如投研、咨询、财务、法务、研究与企业运营。

通用聊天工具的问题：

- 回答停在文本，仍需人工复制和排版。
- 模型声称读了文件或网页，过程没有证据。
- 文件、网页、插件、命令和记忆缺少统一权限边界。
- 中断、重启、误删和升级后难以恢复。

WorkPivot 把一次工作变成带资源范围、持久运行、版本成果和恢复机制的任务。

## 核心组成

| 组成 | 作用 |
| --- | --- |
| 项目与任务 | 组织背景、对话、运行记录和成果 |
| Agent Runtime | 模型、工具、预算、上下文、停止与恢复 |
| 文件与成果 | 上传、解析、版本、预览、下载、回收站 |
| 知识与引用 | 关键词/向量混合检索、来源版本和原文位置 |
| 三层记忆 | 个人、项目、任务事实；自动保存与冲突确认 |
| 业务事实 | 项目对象、事实/关系版本、证据、双时态与冲突确认 |
| Skill/专家/MCP | 把企业方法沉淀为受控、可审查能力 |
| 自动化 | 确认后定时执行，持久队列和历史记录 |
| 隔离执行 | Browser、Worker、Office/PDF 执行器 |

## 与常见产品的心智差异

| 维度 | 通用聊天 | 编程 Agent | WorkPivot |
| --- | --- | --- | --- |
| 核心对象 | 消息 | 代码仓库 | 项目、任务、运行和成果 |
| 最终交付 | 文本 | 代码/补丁 | Office/PDF/报告及可追溯版本 |
| 权限 | 通常较弱 | 工具审批/沙箱 | 任务级文件、网页、记忆、Skill 和写操作范围 |
| 记忆 | 线性会话为主 | 开发者工作记忆 | 个人/项目/任务三层，带来源与冲突确认 |
| 部署 | SaaS | 本机 CLI | 私有化服务端 + Web/桌面/移动客户端 |

## 当前状态

已实现：

- PostgreSQL 数据库链路、多账户隔离、任务和成果版本。
- OpenAI 兼容/Anthropic 模型接入。
- 文件、网页、浏览器、搜索、MCP、Skill、Worker。
- Word/Excel/PPT、直接 PDF 和可选 Office 转 PDF。
- RAG、引用、三层记忆、专家、自动化和回收站。
- 项目业务事实、对象关系、证据历史、冲突确认和 Agent 有界召回。
- 单机 Docker 安装、备份恢复和基础发布材料。

仍在推进：

- 企业身份、组织同步、成员撤权和多人项目协作。
- 复杂 Office 样版的视觉验收、长期稳定性和第二设备验证。
- 正式生产许可、完整运维基线与安全审计。
