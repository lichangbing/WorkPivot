# 后台管理体验优化（2026-10-29）

## 调整内容

| 项目 | 结果 |
|---|---|
| 模型管理 | 移除计价币种、输入单价和输出单价的录入界面；历史用量单价快照保留 |
| 专家模板 | 新增项目经理、投资专家、咨询顾问；通用研究员保留 |
| 默认角色 | 新增开发经理、财务经理、投资研究院、测试经理、咨询顾问 |
| 安全审计 | 菜单与页面改为“安全审计”，主区域使用序号、时间、操作人、请求内容四列表格 |
| 请求内容 | 服务端生成中文操作描述，例如“模型配置 · 修改（成功）”，不显示请求 ID |
| 我的项目 | 从后台菜单和内容路由移除，项目操作统一在用户工作区进行 |

## 验收

- Admin Chromium 验收：模型表单不存在三个价格字段；后台不存在“我的项目”；菜单显示“默认角色”和“安全审计”。
- 安全审计表格验证四个列名、连续序号、分页追加、用户/结果筛选、刷新、导出和确认清理。
- 合成审计数据包含请求 ID，页面断言不会显示该 ID。
- 数据库完整回归继续验证审计鉴权、不可篡改、导出和清理；schema 仍为 v67。
- 本地与生产数据库发布后默认角色 5/5、专家模板 3/3。
- 生产服务镜像已更新，首页、健康接口和管理端容器状态正常。

## 边界

- 移除的是后台价格录入界面，不删除历史模型用量中的单价快照，也不改变已有费用统计的读取兼容性。
- 审计请求内容由服务端的安全分类和 HTTP 方法生成，不读取或展示请求正文、查询字符串、IP、令牌或动态路径。
- “我的项目”仅移除后台入口；原组件代码可保留供兼容，但当前后台路由不可访问。
