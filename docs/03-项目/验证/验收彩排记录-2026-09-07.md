## 彩排发现并已修复的问题

| # | 严重度 | 问题 | 修复 |
|---|--------|------|------|
| 1 | **P0 安全** | **workdir 档 bash 界外路径绕过**：read 被用户拒绝后，模型改用 `bash type C:\...` 读到了界外文件（审计：`bash allow workdir 档放行非高危命令`）——权限引擎不解析命令文本中的路径引用 | permissions.ts：提取命令中的盘符绝对路径，凡引用任务目录/已授权目录之外的命令在 workdir/auto 档仍需单次确认；W2 新增绕过封堵断言 |
| 2 | P1 功能 | **`/stop` 路由服务端不存在**：前端「停止」按钮调用 404，运行中任务无法停止 | app.ts 补 `POST /api/tasks/:id/stop`（abort 循环+审计） |
| 3 | P1 稳定性 | **模型流无停滞超时**：供应商流停滞（无字节）时任务永久卡 running，步数/时长上限无法打断永不返回的 await | sse.ts 空闲超时 180s（分片间计时+clearTimeout 防悬挂 rejection）；两协议客户端 fetch 加 120s 连接超时（响应头到达即撤销） |
| 4 | P2 体验 | **长工具执行期断开感知失效**：SSE 无心跳，TCP 缓冲未满时服务端察觉不到客户端断开（实测挂 14 分钟） | 消息路由每 15s 写 `: ping` 注释帧，死亡 socket 即刻触发 abort |
| 5 | P2 纪律 | 模型在 read 被拒后主动换命令绕过（配合 #1 造成泄漏） | system 提示新增访问纪律：拒绝后不得改用其他手段达成同一目的 |
| 6 | P3 打包 | pnpm 11 `verifyDepsBeforeRun` 默认自动 install 与 electron-builder 内部 install 叠加，曾清脏工作区 | pnpm-workspace.yaml 关闭 verify-deps/confirm-purge；collect-runtime 幂等化 |
