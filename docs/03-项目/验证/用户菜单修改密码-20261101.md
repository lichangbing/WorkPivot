# 用户菜单修改密码验收（2026-11-01）

## 功能

- 用户端左下角点击当前账号打开用户菜单。
- “修改密码”位于“界面风格”上方。
- 菜单继续包含界面风格、本地会话记录和退出登录。
- 修改密码要求当前密码、新密码和确认密码。
- 新密码至少 6 位，不能与当前密码相同，两次输入必须一致。
- 修改成功后撤销该账号全部旧会话、清除当前本地令牌，并提示使用新密码重新登录。

## 实现

- `WorkspaceUserMenu` 增加改密入口和弹窗状态。
- `ChangePasswordDialog` 复用现有 `/api/auth/password` 接口。
- 服务端仍由 `AccountRepository.changePassword` 原子校验当前密码、更新密码哈希、递增 `auth_version` 并撤销会话。

## 验收

- 全 workspace TypeScript：通过。
- ESLint：通过。
- Web 生产构建：通过。
- 本地 Linux 管理员真实登录：通过。
- 真实 Chromium 用户菜单：修改密码位于界面风格上方。
- 改密弹窗：当前密码、新密码、确认新密码字段完整。
- 使用临时账号完成真实 Chromium 改密：错误当前密码被拒绝，正确密码可提交，无浏览器运行异常。
- 改密成功后当前本地令牌被清除，两个旧登录会话访问受保护接口均返回 401。
- 原密码登录返回 401，新密码登录返回 200。
- 临时账号及测试会话已在验收后清理。
