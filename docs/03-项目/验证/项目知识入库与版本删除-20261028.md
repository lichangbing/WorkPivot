## 验证结论

v65 完成从“解析即索引”到“用户确认后才发布知识”的切换。知识、原文版本、记忆和业务事实分别维护状态，不再把同一文件版本的解析结果自动视为项目知识。

已验证：

- 新解析版本只生成候选，未确认时关键词和向量检索均不可见。
- 用户可以只选择部分候选；拒绝和重新审核保留持久状态。
- 解析器指纹升级后旧索引撤销，并重新进入待审核。
- 删除旧版本不改变当前版；删除当前版不自动回退旧版。
- 活跃任务正在使用目标版本时拒绝删除，返回 409。
- 单版本删除清除该版本的知识分片、向量作业、原件对象和模型历史引用。
- 只有被删版本支持的记忆、业务事实和业务关系进入待复核，搜索、自动加载和关系遍历停止返回；用户重新编辑或确认后恢复。
- 多个文件版本、跨任务、跨项目和跨用户边界保持隔离。

## 复现命令

```bash
cd code
pnpm typecheck
pnpm lint
pnpm check:docs
pnpm --filter @workpivot/web build
pnpm --filter @workpivot/mobile build
pnpm eval:knowledge-ui
```

数据库专项需要一次性 PostgreSQL（含 pgvector），并创建数据库名以 `knowledge_test` 开头：

```bash
WORKPIVOT_TEST_PG_DISPOSABLE=1 \
WORKPIVOT_TEST_PG_URL='postgresql://postgres@127.0.0.1:5432/knowledge_test' \
pnpm eval:knowledge-db
```
