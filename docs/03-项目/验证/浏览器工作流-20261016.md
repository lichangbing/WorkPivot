# 单用户浏览器工作流验收（2026-10-16）

## 已确认范围

根据 WorkBuddy 运行与记忆分析，继续当前单用户功能收尾：验证浏览器对话、工具审批与成果、停止、刷新恢复、记忆建议确认及纠错、新任务读取已确认记忆。发现有证据的问题后修复，不引入新 Agent 框架、向量检索、多用户调度或预热池。验收阶段未提交或部署；用户随后授权提交代码，见文末提交检查记录。

## 本批路径与完成标准

既有 rc-browser 仅预置专家建议、恢复记录，database-client-ui 仅模拟 HTTP，均不能替代真实数据库执行链。本批增加独立临时 PostgreSQL + 当前前端/API/执行器/记忆作业的浏览器入口，使用明确标示的可控模型响应。避免读取业务账号和真实密钥。测试账号、资料和数据库均为一次性资源。

验收顺序：生成文本成果与下载 → 慢响应时刷新并停止 → 记忆建议确认 → 纠错前后旧/新值 → 新任务读取 → 专家入口及状态观察。浏览器操作与服务端状态核对相结合。可控模型只验证链路，不用于证明真实模型提取质量、Office 二进制生成或 Skill worker 中断已经验收。

## 结果

### 修复

复现：选择正在执行或已完成的任务后刷新，登录状态保留，但当前任务重置为未选择；重新手选才能查看历史、审批和成果。根因是 DatabaseWorkspace 的 active 只保存在组件内存。

现已在 sessionStorage 按认证用户 ID 保存当前任务 ID。同一标签页刷新后，先取得当前账号的可访问任务列表，再验证并恢复选择；其他账号、已删除/不可访问的 ID 不用于恢复。存储不可用时退回原有导航，不影响登录。仅保存选择标识，不保存聊天正文、附件或密钥，也不自动重放工具。

使用当前源码和重新构建的前端；没有调用实际模型供应商、Skill worker 或办公二进制生成链。新会话复用验证的是工具与数据链，不代表真实模型一定会选择正确检索词。模型等待期间的取消不等同于外部有副作用工具执行期间的取消。

### 使用入口与后续

在 code 目录运行 `pnpm eval:browser-workflow`，需要本地 postgres:15-alpine 镜像，Windows 使用 WSL Ubuntu-24.04。浏览器访问 http://127.0.0.1:39987，测试账号 workflow-test / Workflow-Test-2026!。该固定口令仅用于每次重建的临时本机账号，不可用于业务部署。入口维护 WSL 生命周期，数据库采用 tmpfs 与随机凭据，只开放本机随机数据库端口，结束后清理本次容器。浏览器服务 15 分钟后自动关闭；测试完成也可 POST /fixture/stop 提前正常关闭。

可输入“生成一份浏览器验收报告”“慢速响应，用于验证刷新和停止”“请记住我的个人偏好：报告语言使用中文。”“更正我的个人偏好：报告语言使用英文，替代中文。”；确认建议后切到新任务问“报告语言是什么？”。响应规则为可控测试夹具，不是通用模型服务。
