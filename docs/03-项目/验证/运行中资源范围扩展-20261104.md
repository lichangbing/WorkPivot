# 运行中资源范围扩展验收（2026-11-04）

## 结论

`v0.3.0-rc.5` / schema v72 已完成运行中文件版本和记忆层增量扩展的代码、数据库迁移与工程回归。当前支持在任务运行期间由用户确认新增资料，并在下一安全检查点应用；不支持运行中缩减范围、切换版本或热启用专家。

## 交付范围

- Web 与移动端均提供“运行中资料范围”入口；没有活动运行时不显示该入口。
- 客户端只提交当前范围内不存在的文件和记忆层。
- 服务端使用 `requestId` 保证幂等，使用 `baseRunId + baseEpoch` 拒绝旧页面或旧运行代次。
- 新增文件必须属于当前任务或同一项目；任务删除、项目删除和运行删除会级联清理范围变更记录。
- 范围扩展在同一事务中保存前后快照、撤销旧计划与待处理/已批准未消费审批，生成强制相关的安全点消息，并发出 `scope_changed`。
- 原本已初始化的工具闭包会在工具校验事务中按相邻代次同步；旧闭包不能跳过中间代次。
- 新增记忆层可供后续 `search_memory` / `read_memory` 使用；自动记忆摘要是运行开始时生成的，新层会通过安全点消息提示模型主动检索，不宣称已提前注入所有内容。

## 数据库安全

`workpivot.run_scope_changes` 保存：

```text
id / owner_user_id / task_id / run_id / request_id / base_epoch
added_version_ids / added_memory_scopes
previous_scope / next_scope / created_at
```

表启用并强制 RLS；任务与运行级联删除，新增版本数限制 100，记忆层限制为 `user/project/task`。相同用户、任务和 `requestId` 只能形成一条变更。

## 已知限制

- 运行中不能移出文件、回退版本或关闭记忆层；变更范围仍要求新一代运行。
- 运行中不能热启用专家。专家提示、经验和工具集在运行开始时固定，避免界面承诺与运行时实际能力不一致。
- 范围扩展保证新增资料进入读取范围和在安全点处理，不保证一次扩展后整体任务结果自动正确；仍需真实办公业务样本验证模型是否按新资料修正已有结论。
- 远程正式环境未部署；本文不把本地验收视为正式发布验收。
