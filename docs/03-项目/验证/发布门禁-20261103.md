## 4. 本轮发现并修复的缺陷

1. 非网络写入和隔离执行曾被直接跳过授权登记，随后被成果发布闸门拒绝。
2. 服务端派生 risk 字段曾进入审批摘要，导致合法授权被误判为与实际调用不一致。
3. 后续轮次未选择文件时无法列出本任务成果，导致成果版本链无法继续更新。
4. 后台记忆自动保存可能在另一个任务运行期间改变 epoch，导致运行中止；自动保存现会延后到无活动任务时。
5. 十轮记忆分析的来源 SQL 参数类型错误，导致批次在调用模型前失败。
6. schema v70 数据库升级、故障恢复和测试角色夹具存在版本漂移，本轮已同步。
