# 本地栈完整安装修复（2026-10-28）

## 问题

首次本地部署时，执行器镜像构建中断后静默退化为普通服务端镜像，安装器仍然报告核心健康检查通过。
结果是 OCR、PDF 渲染、LibreOffice 转 PDF 和 PostgreSQL 对话存储没有安装，但部署结果容易被误认为完整。

## 修复

- 安装器默认启用 OCR、PDF、LibreOffice 和 `chat` schema；`--minimal` 才进入精简模式。
- 执行器通过基础镜像 ID 和必需命令校验完整性；服务端镜像变化或能力缺失时自动重建。
- 执行器构建失败或 SearXNG 拉取失败时安装直接中止，不再用缺少能力的镜像冒充执行器。
- 重复执行时允许同一 Compose 项目占用目标端口，并复用已有 `chat` 角色口令。
- 默认使用阿里云 Alpine 镜像源，降低 LibreOffice 与 OCR 依赖下载失败概率。
