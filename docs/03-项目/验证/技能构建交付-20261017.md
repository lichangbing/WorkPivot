# 对话生成私人 Skill、脚本与测试验收

日期：2026-10-17。范围：统一计划 SK-01—05。本地实现与验收完成；未提交、推送或部署。ST 基础定时任务仍待开发，联网抓取、网页登录和全容器调度仍属于下一版本。

## 已交付

- 对话工具 `list_my_skill_builds`、`propose_skill`、`revise_skill_draft`、`validate_skill_draft`、`trial_skill_draft`、`get_skill_build` 接入真实数据库模型运行链路。可从需求生成 SKILL.md、脚本、tests、参考资料及测试清单；生成文本与脚本注释使用中文。生成前读取本人技能摘要，供模型提示同主题修订；当前任务可直接修订，跨任务修改需回到原任务或设置处理。
- 草稿、文件树、发布版本、构建来源和测试报告持久保存于 PostgreSQL。私人技能有服务器分配的稳定内部名称与 skill_id，显示名称可重复；原公共技能继续兼容。
- 数据库 v28 增量迁移隔离私人发布版本与目录。应用管理员不能借管理角色读取其他人的私人正文；原管理发布、回退、启停接口不能绕过私人确认。
- 草稿先校验结构、引用和依赖；脚本型技能必须隔离试运行。Node 脚本自动语法检查，测试必须直接运行包内 tests 入口（Node、可用的 Python 或 shell），禁止用 `true`/`echo` 冒充；测试文件可执行断言；显式选择输入文件版本，默认使用脚本内生成的合成样本。沙箱无网络、资源和时间受限，不安装依赖，不覆盖业务成果。
- 必须在应用弹窗点击“保存并启用”，才能原子写入私人发布版本与加载选择；绑定修订和内容哈希，并发/重复提交只产生一个版本。关闭、稍后处理、继续聊天和自动执行档位都不替代该确认。
- 下一轮按名称、说明发现技能，按需读取正文和资源；已启动任务继续使用原发布版本。修改后需重新校验、测试和确认，历史版本可建立回退草稿。
- 聊天中自动弹出待确认窗口，设置的“我的技能”可再次打开。支持文件预览、修改、新增/移除文本文件、差异、报告、测试输出预览、ZIP 导出、停用、软删除与恢复。
- 普通删除阻止新读取/执行及在途成果发布，保留版本供恢复；恢复为停用状态。来源任务删除或对话撤回使构建失效，不能从旧版本绕过。完整统一回收站与彻底删除仍归原第4项。
- 联合备份包含新表与版本。恢复撤销旧确认、测试状态和私人启用；按最新保留清单处理后，备份后已删除或修订的旧技能内容不会复活。仍有效的保留内容可明确建立新草稿，再验证确认。

## 使用流程

1. 在任务对话中描述技能，或让助手沉淀已验证的方法。可要求包含脚本与 tests。
2. 助手生成私人草稿并校验；执行测试时按现有授权流程确认本次隔离运行。
3. 测试失败时查看报告，要求助手修复，或在窗口修改文件后重新校验和测试。
4. 窗口核对用途、文件、权限、差异及报告；选择“保存并启用”。暂不启用可关闭或仅保存草稿。
5. 下一轮对话明确使用该技能，助手通过 `load_skill` 读取、`execute_skill` 执行并保存指定成果。

例如：“创建一个私人技能：读取 Excel 第二列金额并生成 Word 合计报告，同时生成测试脚本，使用合成数据检查结果。测试通过后让我确认再加载。”

脚本说明和 `skill-test.json` 可使用 `{{skill_root}}`、`{{skill_name}}` 占位符，保存时替换为实际内部目录与名称；脚本内部建议用相对模块引用。测试清单可提供 `command` 与 `outputs`，窗口据此填入默认测试参数。

## 测试入口与限制

- `pnpm eval:database`：隔离 PostgreSQL 回归；默认镜像未缓存时可设置 `WORKPIVOT_TEST_PG_IMAGE=pgvector/pgvector:pg16`。
- `pnpm eval:skill-build`：隔离数据库与真实 Docker 的生成文件树、脚本语法、断言及 Office 测试，需要已有 worker 镜像。可用 `WORKPIVOT_TEST_WORKER_IMAGE` 指定镜像。
- 真实模型显式设置 `WORKPIVOT_LIVE_EVAL=1`，本地配置路径由 `WORKPIVOT_LIVE_ENV_FILE` 提供；模型名可用 `DEEPSEEK_MODEL` 指定。密钥不得写入命令、文档或聊天。`WORKPIVOT_SKILL_LIVE_OFFICE=1` 执行 Office 模型闭环。
- `WORKPIVOT_SKILL_BROWSER_HOLD=1` 临时保留本机验收页十分钟，供手动或浏览器工具核对。停止后清理临时库、沙箱与合成文件；不修改业务部署。
- `pnpm eval:backup-database`：真实恢复往返。所有容器使用测试标签、随机端口和临时数据，不挂载业务卷。

对话生成当前提供文本文件写入，每包最多64个、总文本512KiB、单文件256KiB；测试输入与技能合计16MiB。每次构建最多8次修订、8次试运行；同用户同时最多一个草稿测试。运行失败/中断不伪造通过，租约到期后允许显式重试。

执行能力取决于已有镜像。当前实际验收的是 Node 与预装 Office 库；不能保证任意 Python/系统工具可用，不能自动联网安装依赖。只读目录由版本固定提供，临时沙箱删除不影响持久技能。脚本测试通过只证明对应样例，不保证所有业务输入；仍需用户审阅方法与权限。

基础定时任务、外部分享发布、全栈容器控制、网页学习/抓取、人工登录、精确费用预算与完整统一回收站继续按主计划交付。本批没有启动任何业务定时计划，没有升级运行中的本地或公网服务。部署时需先按现有升级流程安装 v28，再更新 API/前端；不得把本地临时验收页当作正式部署。
