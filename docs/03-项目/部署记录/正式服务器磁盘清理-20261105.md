# 正式服务器磁盘清理（2026-11-05）

## 结果

| 项 | 清理前 | 清理后 |
| --- | --- | --- |
| 已用容量 | 约 36 GB | 约 20 GB |
| 可用容量 | 约 2.2 GB | 约 19 GB |
| 使用率 | 95% | 52% |
| Docker 镜像 | 67 个 | 7 个 |

本次共释放约 16 GB。服务端保持 RC.8，数据库和文件存储就绪，运行中容器未重建。

## 占用原因

- containerd 镜像层约 22 GB，包含大量历史构建和临时版本镜像。
- 两个已退出测试容器占用约 636 MB 可写层。
- 系统 journal 约 400 MB，APT 缓存约 374 MB。
- `/tmp` 保留了重复的 Windows、Android 和 Gradle 构建制品。
- 实际业务数据卷仅约 251 MB，历史备份约 762 MB，不是本次容量告警的主要原因。

## 已执行清理

1. 删除两个已退出容器，释放约 636 MB。
2. 删除创建超过 24 小时且未被容器使用的历史镜像，释放约 3.1 GB。
3. 清理 APT 包缓存。
4. 将 systemd journal 收缩到 100 MB，释放约 300 MB。
5. 删除 `/tmp` 中可重新生成的 Windows/Android 安装包、Gradle 压缩包和临时验收文件。

镜像层回收后，文件系统实际释放约 16 GB。

## 保留内容

- 当前运行镜像：`workpivot-server:rc8-20261105`。
- 回退镜像：`workpivot-server:rc7-20261105`。
- PostgreSQL、Prometheus、SearXNG 和 Browser 当前镜像。
- `workpivot_postgres`、`workpivot_files`、`workpivot_prometheus-data` 等业务卷。
- `/root/workpivot-backups` 下 RC.6、RC.7、RC.8 等历史联合备份。
- 正式下载页当前使用的 Android 1.11 和 Windows RC.8 制品。

## 后续策略

- 每次正式发布后只保留当前版本和一个可验证的回退版本。
- 构建镜像和临时安装包完成后及时清理，不长期放在 `/tmp`。
- 联合备份继续按保留周期归档；删除前必须验证可读性和异地副本。
- 根分区使用率达到 80% 时预警，达到 90% 时停止新发布并先处理容量。
