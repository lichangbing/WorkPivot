## 1. 技能中心（左栏「技能与工具」入口 → 全屏页，2026-08-29 用户确认拆分为两个独立 Tab）

**Tab 1 · 技能市场（官方/公共技能）**：
- 内容=管理员发布的企业公共技能（S01）+ 随产品发行的官方技能包（文档四件套/深度调研等）——**统一以「市场」形态展示**：卡片流（名称/描述/分类/更新时间/来源标签「官方·企业」），支持分类筛选与搜索
- 权限：只读；操作=「安装到我的技能」（复制为个人副本）/ 查看详情
- **用户自己的技能不在此 Tab 展示**（两侧彻底拆分，避免混看）
- 更新提示：市场技能有新版本时卡片标「有更新」（管理员推送后）

**Tab 2 · 我的技能（个人+项目）**：
- 分组：项目技能（当前项目 `.workpivot/skills/`）/ 我的技能（`~/.workpivot/skills/`）
- 每行：技能名 / 描述 / 触发方式标签（自动｜仅手动）/ 更新时间 / 来源标记（自建·从市场安装·从文档生成·从对话沉淀）/ 操作（编辑·试运行·删除·导出）
- 顶部：搜索 + 「新建技能」+ 「从文档生成」

**两 Tab 关系**：市场安装=复制副本进「我的技能」（之后独立演进，不随市场更新自动变化，仅提示有新版本可重新安装覆盖）。

## 2. 技能编辑器（居中大面板，双 Tab）

**Tab A · 说明（MD 层）**：
- 上部表单区：名称（技能标识，改名的迁移规则见 §6-3）/ 显示描述（触发词写入此字段——空则技能永不自动触发，编辑器实时提示）/ 触发方式（自动 ｜ 仅手动 `disable-model-invocation`）/ 适用范围（全局·当前项目）
- 下部正文编辑器：Markdown 语法高亮；**模板骨架一键插入**（触发条件→编号步骤→注意事项→验证步骤，Hermes 好技能范式）；右侧实时预览
- 顶部常驻提示条：「保存即热生效——下一条任务立即使用新版本」（D01）

**Tab B · 文件（代码层）**：
- 左：技能目录树（SKILL.md / references/ / scripts/ / templates/ / assets/），右键新建/上传/重命名/删除
- 右：文件编辑器（按扩展名语法高亮：py/js/sh/md/json）；**脚本编辑区顶部黄色提示**：「脚本将始终在沙箱内执行（I01）；企业策略可禁用成员脚本」
- 保存：SKILL.md 即时生效；scripts 保存后试运行可用

**公共技能的查看态**：两个 Tab 只读 + 「复制为我的技能」按钮（复制后全权）。

## 3. 试运行（调试闭环，编辑器右上「试运行」）

面板（右侧抽屉）：
1. **模拟输入**：一句任务描述（如「帮我把这批数据做成柱状图」）
2. **命中判定**：显示该技能是否会被自动触发（匹配描述触发词）+ 触发词命中高亮；未命中给出原因（描述缺触发词等）与修改建议
3. **注入预览**：技能目录注入形态（name+description 如何出现在系统提示词）；正文加载预览
4. **执行观察**（可选「真执行」开关）：实际跑一轮模拟任务，主线展示该技能被调用后的行为；**脚本类技能真实执行并显示输出**（沙箱内）；费用提示（真执行消耗模型调用）

## 4. 三种创建方式

### 4.1 空白模板
新建 → 编辑器打开，骨架预填。

### 4.2 从文档生成（D05 可控流水线的界面）
向导三步：
1. **上传文档**（PDF/Word/MD/txt；≤20MB）
2. **抽取预览**：按固定 schema 展示抽取结果——技能名（可改）/ 适用场景 / 前置条件 / 步骤序列（每步：动作·输入·输出）/ 注意事项 / 验证方法；**每字段标注依据**（原文引用片段折叠可查）；低置信字段黄色高亮 + 「请重点核对」；抽取失败显示「该文档不适合提炼技能：{原因}」（不硬编）
3. **编辑确认**：进入技能编辑器（预填抽取结果），用户逐段核对修改后保存——**人工编辑为必经环节**（D05 可控性原则）

### 4.3 从对话沉淀
对话页「把这次做法存为技能」入口（任务成功后收尾卡亦提供）→ 抽取本会话过程生成草稿 → 同 4.1 的第 2-3 步（预览+编辑确认）。

## 5. 专家配置（后台，管理员）

列表页（后台侧栏「专家配置」）：专家名/描述/绑定技能数/数据源/状态/排序（用户端下拉顺序）。新建/编辑表单：

| 字段 | 规格 |
|------|------|
| 名称 + 显示描述 | 用户端任务创建下拉可见 |
| 人格提示词（agent.md 正文） | 多行编辑器（语法高亮）；支持直接上传 .md；**提示企业默认层红线不可覆盖**（S03 叠加说明） |
| maxTurns 会话预算 | 默认 50，1-200 |
| 绑定技能 | 多选（公共+项目技能；不可选他人私有） |
| 绑定数据源 | 多选（S02 连接器 + S02a RAG 的可见范围预置） |
| 开场提示（可选） | 用户选该专家新建任务时的默认首句 |
| 状态 | 启用/停用（停用后用户端 60s 内不可选） |

内置专家模板（调研专员/文档写作/数据分析/PPT 设计）随产品发行，可改可停；数量不设限。

## 6. 边界场景

| # | 场景 | 处理 |
|---|------|------|
| 1 | 技能名与公共技能重名 | 个人/项目层覆盖公共（同名就近优先，D01 规则）；列表显示「覆盖公共版」标记 |
| 2 | 编辑中的技能正被任务使用 | 保存对新任务生效；运行中任务沿用旧版（转写记录版本号） |
| 3 | 技能改名 | 内部以目录名稳定的 ID 关联（重命名仅改显示名，不破坏引用） |
| 4 | 从文档生成含敏感信息 | 抽取预览页提示；保存前用户自审（企业策略可加敏感词扫描，M05） |
| 5 | 删除被专家绑定的技能 | 二次确认列出受影响专家；确认后专家绑定自动移除 |
| 6 | 脚本执行被企业策略禁用 | Tab B 只读 + 提示「管理员已禁用个人脚本」；MD 层不受影响 |

## 7. 验收清单

- [ ] 三组技能列表权限正确；公共技能只读+复制副本可用
- [ ] 编辑器双 Tab；SKILL.md 保存后下一条任务热生效（不改代码不重启）
- [ ] 试运行：命中判定+注入预览+真执行（脚本沙箱内跑通并显示输出）
- [ ] 从文档生成：同一文档重复生成 3 次结构一致（schema 断言）；低置信字段标黄；编辑必经
- [ ] 专家配置全字段；停用 60s 内用户端不可选；红线叠加说明可见
- [ ] Word 模板管理（H01 关联）：上传/预览/设默认/按类型关联（挂后台「文档模板」，界面归 PRD-04 导航，规格同 §5 表格型管理）
- [ ] 技能/专家导出为独立文件，可导入（企业内分享不走市场）
