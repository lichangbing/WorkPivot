## J. 多用户、企业与私有化交付 ⚠️

| 编号 | 需求 | 优先级 | 调研依据 |
|------|------|--------|----------|
| J01 | 多账号（任务历史/用量按人隔离） | P1（单机先行时） | OWB 多租户（账号级共用）；WorkBuddy 账号体系 |
| J08 | **统一登录与企业管理账户制（2026-08-28 定稿 v2）**：① **通用能力：标准 OAuth 2.0/OIDC 认证体系接入**——任何标准 IdP（企业微信/钉钉/Keycloak/Azure AD/Authing 等）经统一认证适配层接入 ② **飞书为首个深度适配**（扫码/授权登录 + 组织架构同步，因目标客群主用飞书）③ **无外部 IdP 时用内置账户管理**（账密登录）④ **管理员分配账户制**：无自主注册，管理员创建/分配/停用账户后方可登录。**术语边界**：此为私有化下的「企业封闭账户体系」，非 SaaS 多租户；未来 SaaS 化为同一模型的超集扩展（+租户隔离+计费） | P1（企业部署形态必须；MVP 单机可先内置账户制） | WorkBuddy 企业版飞书/企微集成+SSO 域名；OWB 管理员分配制；认证解决「是谁」，角色权限走自有 RBAC（J01/J04）；适配层设计与连接器层（D03）同构 |
| J02 | 私有化部署包（离线安装、打包定制客户端、成员授权分发） | P1（首对外版本必须） | WorkBuddy 专有云九步开通流程（20 分钟部署） |
| J03 | 多租户硬隔离（进程/容器级，非仅账号级） | P2 | OWB 诚实警示「应用层挡不住 shell 读别人产出」 |
| J04 | 企业管理后台（模型/专家/Skill/知识库/白名单/日志管理） | P2 | WorkBuddy 企业控制台能力清单 |
| J05 | 用量统计与积分额度（可选） | P2 | WorkBuddy credits；OWB 可选积分 |
| J06 | 公共授权 vs 个人授权连接器分离（协作场景禁个人授权） | P2 | WorkBuddy 项目层权限模型精华 |
| J09 | **连接器管理员角色与公共授权模型（2026-08-28 新增）**：通用型 Skill/MCP（网站访问、数据库取数等）的配置权归**独立的「连接器管理员」角色**，不归企业管理员（职责分离：管理员已掌握账户体系，不再叠加敏感凭据）；凭据**绑定连接器资源而非个人账号**（加密库存储、可轮换、离职不带走），公共连接器调用审计仅连接器管理员与企业管理员可见；普通成员只可使用、不可见凭据，可另配个人授权连接器（票据仅本地）。角色可兼任（小企业一人多角） | P2（企业部署形态；连接器凭据加密本身是 P0/I04） | WorkBuddy「公共授权/个人授权」双轨+协作禁个人授权+调用日志管理员可见；OpenClaw auth-profiles 按代理隔离 |
