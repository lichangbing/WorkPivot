## 1. 导航与入口

左栏用户区块齿轮 / 用户菜单「个人资料」→ 设置页（左侧分区导航+右侧内容，移动端折叠）。服务端形态浏览器同路径。

## 2. 分区规格

### 2.1 通用
显示名称（≤32 字）/ 主题（浅色·深色·跟随系统，全局即时切换）/ 字号（标准·大）/ 默认工作目录（单机形态）/ 语言（简体中文，i18n 已决策暂不做——置灰显示）。

### 2.2 通知（A06）
- 任务完成 / 任务失败 / 等待授权与提问——三类各自开关（默认全开）
- **免打扰时段**：起止时间（默认 22:00-08:00）+「免打扰期间不弹但计入未读」说明
- 声音开关；点击通知跳转对应任务（默认开）

### 2.3 安全（承接 PRD-01 决策）
- 修改密码（当前密码+新密码+确认；强度规则同注册）
- **锁屏**：开关（默认关）+ 超时（10/30/60 分钟，默认 30）
- **登录设备管理**（多端在线）：列表=设备名/平台/最近活跃/当前设备标记；单设备「下线」（该端 token 失效）；「全部其他设备下线」
- 登出（当前设备）

### 2.4 权限与执行（I02 个人侧）
- 默认权限档位选择（只看不动/每步都问/自动改文件/全自动；**企业强制档时本项锁定并提示**——M05）
- 界外授权白名单管理：路径列表（增删；「永久」项可在此移除）；企业策略禁用永久白名单时隐藏「永久」能力
- 高危命令二次确认：固定开启（不可关）

### 2.5 数据与备份（A08）
- **备份**：目标目录选择 → 「立即备份」（含 data/config/skills/缓存设置；workspace 可选勾选）→ 进度与结果（文件路径+大小）
- **恢复**：选择备份包（校验 manifest 版本兼容）→ **自动 before-restore 安全备份** → 恢复 → 提示重启
- **缓存治理**（PRD-02 §8）：查看占用 / 上限调整（默认 500MB）/ 立即清理 / 登出时清理选项
- 服务端形态差异：备份/恢复仅管理员可执行（数据在服务端）——普通成员本页显示「由管理员统一管理」

### 2.6 语音（A09，P2 占位）
语音输入（本地 Whisper 模型下载 / 云端 API 选择）+ TTS 朗读开关。P2 前显示「即将支持」。

### 2.7 关于与更新（A07）
- 版本号 / 构建信息 / 更新源地址（管理员配置显示，个人不可改）
- **检查更新**：手动检查 → 有新版（版本说明+增量大小）→「下载并安装」（下载完提示重启，不打断进行中任务）/「稍后」
- **回滚到上一版本**：保留上一版安装目录；二次确认+回滚说明
- 企业强制更新策略时：仅「立即更新」按钮（M05 联动）
- 开源许可（K05）：THIRD_PARTY_NOTICES 查看入口

## 3. 边界场景

| # | 场景 | 处理 |
|---|------|------|
| 1 | 恢复包版本高于当前应用 | 拒绝并提示「请先升级应用至 X.Y」 |
| 2 | 更新下载中断电 | 断点续传；安装未开始则不影响现有版本 |
| 3 | 回滚后数据结构已升级 | 回滚仅应用主体；数据迁移标记检测，不兼容则恢复备份说明 |
| 4 | 免打扰时段任务等待授权 | 不弹通知但应用内未读+任务状态正常（不因免打扰丢授权） |
| 5 | 企业锁定权限档 vs 个人默认 | 企业强制优先；个人设置项只读+锁定图标 |
| 6 | 全部设备下线时正在跑任务 | 服务端任务继续；各端重新登录 |

## 4. 验收清单

- [ ] 主题三态即时切换；免打扰生效且不丢未读
- [ ] 改密/锁屏/单设备下线/全部下线行为正确（多端实测）
- [ ] 备份→恢复往返完整（含 before-restore 自动备份）；版本不兼容拒绝
- [ ] 缓存上限调整与清理生效；登出清理选项
- [ ] 检查更新/增量下载/重启安装/回滚上一版全流程（内网更新源）
- [ ] 企业强制档/强制更新联动锁定表现正确
- [ ] THIRD_PARTY_NOTICES 可查看
