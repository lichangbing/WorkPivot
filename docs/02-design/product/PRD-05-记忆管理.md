## 1. 个人记忆管理页（设置 → 记忆）

**分区一 · 手写区（MEMORY.md）**：富文本/Markdown 编辑器（所见即所得标题列表）；「每轮会话自动注入」说明常驻；保存即时生效（下次会话）。

**分区二 · 条目区（AI 自动记录）**：列表=内容 / 记录时间 / 来源任务（点击跳该任务）/ 操作（编辑·删除）；搜索；去重规则说明（同义条目自动合并标注）。

**分区三 · 总控**：
- **一键关闭记忆功能**（E01）：二次确认「关闭后新会话不再记录也不注入；已存记忆保留可随时重开」
- 导出 Markdown（E05）；导入（P2）
- 统计条：手写区 N 条 / 条目区 M 条 / 本月新增 K

**隐私常驻提示**：记忆仅存本地/本企业服务器，不进任何遥测。

## 2. 晋升确认卡（对话内，E01 确认流）

触发：AI 判断某条目值得进入长期记忆（手写区/主题文件）时弹出。卡片内容：
- 拟晋升内容（可就地编辑）
- 理由（AI 填写：如「连续 3 次任务用到此偏好」）
- 去留选项：**晋升并保存**（写入对应分区）/ 保留为条目（默认不晋升）/ 删除该条目
- 勾选项「同类内容以后不再询问」（加入抑制清单，可在设置中恢复询问）

频率控制：每会话晋升卡 ≤2 张（防打扰）；关闭记忆功能后不触发。

## 3. 项目记忆面板（左栏「项目记忆」入口 → 全屏/大面板）

- **Tab 长期记忆**：项目 `MEMORY.md` 编辑器（项目背景/约束/决策——Markdown 编辑+保存生效）
- **Tab 按日日志**：`YYYY-MM-DD.md` 列表（日期/摘要行），点开只读查看；「今日+昨日自动注入」规则说明
- **Tab 记忆使用情况**（E03 透明性）：最近 20 次任务中「项目记忆命中了什么」——任务/命中片段/注入 token 数；让用户看见记忆在干活
- 项目归档提示：项目删除时记忆随目录处理（提示备份）

## 4. 上下文查看与管理（A10，对话页 `/usage` 命令 + 面板）

**面板布局**（对话区右滑抽屉或 `/usage` 全屏）：
1. **token 分解条**（可视化横条）：系统提示 / 企业默认层(S03) / 记忆（手写+条目+项目）/ 历史消息 / 工具结果 / 本轮输入 各占比与数值
2. **组成清单**（可操作）：当前会话带了哪些——记忆条目逐条（可**单条移除**，移除仅本会话生效）/ @引用文件列表（可移除）/ 企业层（只读标识）
3. **操作**：`/compress` 手动压缩按钮（显示预估可释放量）；自动压缩阈值（管理员配置的当前值展示，个人不可改）
4. 压缩历史：本会话已压缩次数与摘要卡（中文摘要，可展开对照转写原文——PRD-02 §8 缓存支撑）

**透明性规则**：所有注入内容（记忆/隐藏提醒）在面板中可见可移除（本会话级）——「AI 带着什么在思考」对用户透明。

## 5. 边界场景

| # | 场景 | 处理 |
|---|------|------|
| 1 | 手写区被 AI 误改 | 仅晋升流程可写手写区且需确认卡；编辑器带版本历史（可回退） |
| 2 | 条目区含过时/错误信息 | 用户编辑/删除即时生效；记忆检索命中已删条目立即失效 |
| 3 | 关闭记忆后重新开启 | 历史条目恢复可用；关闭期间不补记 |
| 4 | 多端同时编辑手写区 | 服务端权威+冲突提示（后保存者收到覆盖确认） |
| 5 | 上下文面板移除记忆后新会话 | 移除仅本会话；新会话恢复注入 |
| 6 | 项目记忆与个人记忆冲突（同一事实不同值） | 个人记忆优先（就近）；面板显示冲突提示供用户修正 |

## 6. 验收清单

- [ ] 手写区编辑保存后下次会话注入生效；条目区增删即时
- [ ] 关闭记忆：新会话零注入（断言）；重开恢复
- [ ] 晋升卡：内容可编辑/三选项/每会话 ≤2 张/抑制清单可恢复
- [ ] 项目记忆三 Tab；「使用情况」能展示命中片段与 token 数
- [ ] /usage 分解条与实际请求 token 误差 <5%；单条移除仅本会话生效
- [ ] /compress 手动压缩+压缩摘要中文呈现+对照转写
- [ ] 导出 Markdown 结构完整可再导入（P2 验导入）
