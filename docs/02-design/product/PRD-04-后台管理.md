## 1. 框架（M01）

- **入口**：主界面右上「后台管理」（仅企业管理员/连接器管理员可见）→ 新 Tab/浏览器路径 `/admin`
- **导航**（左侧栏，按角色过滤）：仪表盘（P2）/ **用户与角色**（PRD-01）/ **模型管理** / **连接器配置**（连接器管理员可见）/ **RAG 接入**（连接器管理员）/ **公共技能**（连接器管理员）/ **文档模板** / **专家配置**（PRD-03 §5）/ **默认 Agent 定义** / **审计日志** / 策略设置（P2，M05）
- 角色可见性：企业管理员=全部；连接器管理员=仅其职责页（连接器/RAG/公共技能/模板）；普通成员无入口
- 部署差异：拓扑二（服务端）=浏览器直接访问；拓扑一（单机）=同一界面嵌在应用设置区（本机管理员=本人）

## 2. 模型管理（M03 定稿的界面规格）

**列表**：模型名（用户可见名）/ 供应商协议（OpenAI 兼容·Anthropic）/ 分组（本地池·云池）/ 可见范围（全员·部门）/ 默认标记 / 健康度（近 20 次成败）/ 状态 / 操作。

**新增/编辑弹窗**（以 OpenAI 接口模式为主）：

| 字段 | 规格 |
|------|------|
| 显示名称 | 用户选择器所见 |
| 协议 | OpenAI 兼容（默认）/ Anthropic |
| Base URL | 如 `http://内网:8000/v1`；预设下拉（DeepSeek/vLLM/Ollama/Kimi…自动填） |
| API Key | 密文输入，I04 加密存储；界面永不回显 |
| 模型 ID | 如 `deepseek-chat` |
| 上下文长度 / 能力位 | 工具调用·图片·推理（影响任务路由提示） |
| 分组 | 本地池 / 云池 |
| 可见范围 | 全员 / 按部门多选（J07 组织架构） |
| **连通测试** | 保存前必过：发一条真实请求，失败显示具体报错（C02 验活） |

**推荐规则区**（C04）：任务类型 → 模型映射表；类型预设（文档生成/数据分析/深度调研/通用对话）可增改；每行=类型+推荐模型+排序；「用户可改选」固定开启。

**并发配置区**（M03）：企业最大并发会话数（默认 20）/ 单用户并行任务上限（默认 8）/ 按模型分档并发表（如旗舰 5、轻量不限）。

**停用**：二次确认（可见范围用户影响数）；停用后用户端 60s 内消失，运行中任务不中断。

## 3. 连接器配置（S02）

**列表**：连接器名 / 类型（数据库·HTTP API·内网站点）/ 运行位置（服务端公共·个人模板）/ 凭据状态（脱敏）/ 使用范围 / 调用次数（近 7 天）/ 状态。

**新增向导**：
1. 类型选择：数据库（SQLite/MySQL/PostgreSQL/SQL Server 只读起步）/ HTTP API / 内网站点抓取
2. 连接配置（按类型）：数据库=主机·端口·库名·账号·密码（I04 加密，成员端永不落盘）+ **表白名单**（只勾选可查的表）；HTTP=地址·鉴权头；站点=域名白名单
3. 工具启停：自动发现的工具清单，逐个启用/禁用（**写操作默认禁用**，启用需二次确认+审计加严）
4. 使用范围：全员 / 部门 / 指定项目
5. 测试连接 → 保存（凭据入服务端加密库）

**启停即时性**：停用 → 成员端下轮对话工具消失（≤60s）；调用审计链接到 §7。

## 4. RAG 接入（S02a）

表单：服务地址 / API Key（I04）/ 检索接口模式（标准 REST 预设：query→top-k+来源；自定义请求模板 P2）/ top-k 默认值 / 使用范围。**连通测试**（发一条真实检索显示返回片段）。启停。无 RAG 配置时该页显示引导态（「可对接 Dify/MaxKB/RAGFlow 等，填 API 即可」）。

## 5. 默认 Agent 定义（S03）

- **编辑器**：agent.md（frontmatter+正文语法高亮）；分层组装预览（平台基础层→**企业层（本页）**→用户层只读示意）；「以下约束不可覆盖」区块用标记语法包裹
- **版本**：保存生成版本号；历史版本列表+回滚；生效规则=新会话即时，进行中会话不中断
- **透明性**：成员端可查看当前生效的企业默认指令（只读入口）

## 6. 公共技能（S01）与文档模板（H01）

**公共技能**：上传技能包（目录/zip）/ 新建（跳转 PRD-03 编辑器的公共模式）/ 版本管理（更新推送全员提示+回滚）/ 使用范围（全员·部门）/ 成员只读规则说明。**配置型技能**：发布时预填参数表单（如数据源地址）。

**文档模板**：Word/PPT 模板上传（.docx/.pptx）/ 预览（首页缩略图）/ 设为默认 / **按类型关联**（同 C04 任务类型：如「尽调报告→尽调模板」）/ 启停。

## 7. 审计日志（M06）

统一查询：时间范围 / 用户 / 事件类型（登录·任务操作·危险命令·界外授权·连接器调用·RAG 检索·模型配置变更·后台操作）/ 关键字。列表=时间·用户·事件·对象·结果·详情（展开：参数摘要/命令哈希/授权选项）。**导出 CSV**。连接器调用页签：谁·何时·哪个连接器·哪个工具·参数摘要（连接器管理员+企业管理员可见）。

## 8. 策略设置（M05，P2）

默认权限档位强制 / 禁用永久界外白名单 / URL·命令黑白名单 / 成员脚本开关 / 更新策略（强制·可选）。MVP 以本地配置文件+文档替代。

## 9. 边界场景

| # | 场景 | 处理 |
|---|------|------|
| 1 | 删除最后一个可见模型 | 拒绝：「至少保留一个启用模型」 |
| 2 | 连接器管理员修改凭据时正被调用 | 新凭据对下一次连接生效；进行中调用不中断 |
| 3 | RAG 服务宕机 | 检索工具返回「知识库暂不可用」，任务继续（降级不阻断） |
| 4 | 默认 agent.md 语法错误 | 保存前校验 frontmatter；错误定位提示，阻止保存 |
| 5 | 并发配置为 0 或负数 | 表单校验最小值 1 |
| 6 | 管理员停用自己（非最后管理员） | 允许（PRD-01 规则：可停用他人与自己，仅最后一个企业管理员受保护） |

## 10. 验收清单

- [ ] 角色可见性：连接器管理员仅见职责页；普通成员无后台入口
- [ ] 模型新增：预设填 URL→测试连通→保存→可见范围生效→用户端选择器出现（≤60s）
- [ ] 推荐规则配置后新任务按类型预选+「推荐」标注
- [ ] 并发三档配置生效（企业总并发排队/单用户上限/模型分档）

- [ ] 公共技能版本推送与回滚；文档模板按类型关联到 H01 生成
