## 1. 目标

为管理员提供可操作的账户和聊天额度管理，同时保证公开服务器不会因开放注册、无限提问或不安全浏览器来源而扩大攻击面。

## 2. 角色

| 角色 | 能力 |
| --- | --- |
| 平台管理员 | 创建和管理用户、模型、默认技能和全局配额；不可读取其他用户私人正文 |
| 普通管理员 | 管理用户和运行状态；不得停用/降级平台管理员 |
| 成员 | 使用自己的项目、任务、文件和记忆；只能管理自己的会话 |
| 未认证访问者 | 仅可登录或在管理员明确开放时自助注册 |

## 3. 注册策略

### 默认

- 空数据库允许创建第一个平台管理员。
- 首个管理员创建后，自助注册默认关闭。
- 新账户由管理员创建，并设置临时密码和角色；四项额度默认不限。

### 可配置

管理员可以切换：

| 模式 | 行为 |
| --- | --- |
| 仅管理员创建 `closed` | 登录页不显示注册入口，公开注册 API 返回 403 |
| 自助注册 `open` | 登录页显示注册，默认使用[限额管理](PRD-09-限额管理.md)中配置的对话、Token、上传和并发额度 |

策略带 revision。两个管理员并发修改时只有一个成功，另一个收到版本冲突。

## 4. 用户管理

管理员可查看：

- 用户名、邮箱、角色、平台管理员标记。
- 启用/停用状态。
- 活动会话数、创建时间和最近登录时间。

管理员可执行：

- 创建用户并生成必须修改的临时密码。
- 修改邮箱和角色。
- 重置密码并撤销旧会话。
- 撤销全部登录会话。
- 停用/启用账户。
- 重置当前限额周期（在独立“限额管理”页面）。

限制：

- 用户名创建后不可修改。
- 平台管理员的角色、状态和额度受保护。
- 管理员不能停用自己或修改自己的角色。
- 不能停用或降级最后一个有效管理员。
- 管理员不能读取用户私人聊天、文件正文和记忆正文。

## 5. 聊天限制

### 用户限额

- 对话额度按账号设置，单位为“用户消息轮次”；Token、上传流量和并发任务限制见[PRD-09](PRD-09-限额管理.md)。
- 每天北京时间 12:00 重置。
- `0` 表示不限。
- 模型失败时是否计数遵循实际运行创建规则；重复请求不会重复计数。
- 达到上限时返回 HTTP 429 和明确提示。
- 管理员可调整额度或重置当前周期。

### 输入边界

- 请求体限制 1 MiB；附件按上传接口限制。
- 单次运行消息、上下文、步骤和工具调用均有服务端上限。
- 同一任务只允许一个活动运行。
- 同一任务和请求标识重放返回原结果，不重复执行副作用。

## 6. 访问安全

### 传输与代理

- 公网入口必须使用 TLS。
- 服务端容器只绑定 `127.0.0.1`，由反向代理提供公网入口。
- 反向代理设置 HSTS、CSP、`X-Content-Type-Options`、禁止 iframe、Referrer Policy 和 Permissions Policy。
- 登录限流读取代理传递的真实客户端地址，但审计不保存密码或请求正文。

### 来源控制

- 手机内置页面来源必须显式列入 `WORKPIVOT_MOBILE_ORIGINS`。
- 默认只允许 `https://localhost` 和 `capacitor://localhost`。
- 不使用 `*`，不启用跨域 Cookie；客户端使用 Bearer Token。
- 手机令牌存放在系统 Keychain/Keystore，不写入本地明文。

### 身份与会话

- 密码使用 bcrypt 哈希；未知用户也执行固定占位校验，降低用户名枚举时序差异。
- 登录和注册接口有 IP 与用户名双桶短时限流。
- 会话可撤销；密码修改、重置和账户停用立即使旧会话失效。
- 数据访问继续由 PostgreSQL RLS 强制用户隔离。

## 7. 异常处理

| 情况 | 结果 |
| --- | --- |
| 自助注册关闭 | 403，并提示联系管理员 |
| 额度耗尽 | 429，显示额度和北京时间重置规则 |
| 用户被停用 | 登录失败；已有会话被撤销 |
| 重复修改额度 | revision 冲突，要求刷新 |
| 最后一个管理员被停用 | 409，操作拒绝 |
| 跨域来源不在白名单 | 不返回 CORS 允许头 |
| 登录尝试过多 | 429，带 `Retry-After` 并记录限流审计 |

- [x] 管理员创建用户时可设置邮箱和角色；新账户四项额度默认不限。
- [x] 独立限额管理支持修改四项额度、停用用户、撤销会话和重置当前用量。
- [x] 停用用户的旧会话失效且无法重新登录。
- [x] 平台管理员和最后一个管理员受保护。
- [x] 手机来源跨域预检返回明确 `Access-Control-Allow-Origin`。
- [x] HTTPS 入口带安全头。
