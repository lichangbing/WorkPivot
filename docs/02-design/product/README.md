## PRD 使用规范

模块 PRD 统一回答：

1. 谁在什么场景完成什么任务。
2. 正常流程、状态与关键页面。
3. 当前范围和非目标。
4. 权限、数据、失败、取消、恢复与删除。
5. 可执行的功能编号和验收标准。
6. 依赖、开放问题和变更记录。

写作约定：

- 产品行为以 `prd/` 中的当前文档为准；历史需求只用于追溯。
- 不用“支持”“完善”代替可观察行为；写清输入、处理、输出和失败提示。
- 计划能力必须标注“设计/待实现”，不能因原型或技术研究存在而写成已上线。
- 页面原型只验证信息架构，不代表权限、接口或数据边界已经实现。
- 原型数量不随需求增长无限复制；模块稳定后保留入口页和关键状态。
