# WorkPivot 应用图标

2026-10-19 用户确认采用蓝青渐变圆角底与白色折带 W。中央转折呼应 Pivot，白色主体保证缩小后仍可辨识。原稿由内置 imagegen 工具生成，保留在 `assets/workpivot-icon-concept-v1.png`；未在客户端运行时调用生成服务。

## 应用位置

- `code/apps/desktop/build/icon.png`：1024px 透明 PNG，供 Linux 打包、桌面窗口及托盘使用。
- `code/apps/desktop/build/icon.ico`：Windows 多尺寸图标，包含16、24、32、48、64、128、256px。
- `code/apps/desktop/build/icon.icns`：macOS 图标容器。
- `code/apps/web/public/favicon.png`：64px 标签页图标，主界面和管理后台共用。

仅对已确认图稿做尺寸及格式转换，没有重新生成或修改图形。桌面品牌资源单独解除 build 目录忽略规则，其他打包产物继续忽略。桌面窗口和托盘在客户端重启后生效；网页图标可能需要强制刷新缓存。Windows 目前仍关闭可执行文件资源修改/签名，ICO已配置，但本轮未在Windows验收可执行文件图标。

## 验证

本轮检查 PNG/ICO/ICNS 可读取、尺寸有效，已查看64px缩略图；Web构建、桌面TypeScript及相关ESLint通过，Linux解压包打包通过，资源中包含新图标，原缺少icon.png的警告消失。本机既有 chrome-sandbox 的 root:root/4755 在打包时保留并恢复，无需再次设置。未对Windows/macOS安装包做实机验收。
