## 设计评审门槛

一般功能：

1. PRD 明确用户、流程、异常、权限和验收。
2. 系统边界和数据归属清楚。
3. 失败、取消、恢复和删除路径可实现。

涉及以下变化时必须增加架构专题和 ADR：

- 新存储系统或数据模型重大调整。
- 新信任边界、外部服务或宿主权限。
- 多租户、身份联合、公开共享和跨项目数据流。
- 自动执行、不可逆副作用或新审批模型。
- 会改变兼容性、升级或回滚方式的基础设施选择。

实现完成后更新状态与验收证据。历史日期记录保留原文，但不得覆盖当前 PRD、架构总览和项目状态页。
