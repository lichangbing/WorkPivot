# 共享浏览器与悬浮侧栏

2026-10-17用户确认：现有右侧栏全部内容迁移到对话右上方的可固定/隐藏悬浮区；右侧改为真实浏览器，支持持续点击、输入及导航；用户与AI共享当前对话的同一个浏览器页面。

## 实施范围

- Web/Electron共用服务端Chromium画面与输入转发，不用iframe模拟外站，也不因站点拒绝嵌入而失效。
- 每个账号、对话独立上下文；后台根据认证身份和任务计算不可猜测会话键，用户不能指定他人会话。刷新可重连，切换任务不会混用；空闲超时和显式关闭释放上下文，服务重启不保留状态。
- 右侧地址栏、前进/后退/刷新、视口调整、点击/滚动/键盘/粘贴；持续获取实际页面截图。不是本地浏览器标签页，不承诺视频、音频、下载、登录持久化或验证码专用接管。
- AI的browser_visit默认接入当前对话会话，可省略URL读取当前页面；带URL时按需导航。AI动作仍需确认，用户直接操作即为该动作授权。用户与AI操作串行，忙碌时显示状态，不交错覆盖。
- 自动化继续使用一次性浏览器及来源白名单，不借用用户正在操作的页面。公网地址校验、DNS固定连接和GET读取限制保留，登录提交/非GET请求仍不支持。
- 任务监控、上传资料、成果、技能/MCP、三层记忆全部保留在悬浮区；最新任务/成果优先，展开/固定/隐藏可控制，不占右侧浏览器宽度。

## 验收

验证同页面用户输入后AI读取、AI操作后右侧画面更新、前后导航、刷新重连、账号/任务隔离、忙碌互斥、关闭/过期释放、失败提示、悬浮内容完整及固定/隐藏。与网页读取基础功能部署记录分开标记，未经实际验证不标记完成。
