## 编写要求

新架构文档从[_template-architecture.md](_template-architecture.md)开始，至少包含：

- 背景、问题、目标和非目标。
- 组件职责、正常/失败流程、数据生命周期和信任边界。
- 权限、日志、迁移、回退和可观测性。
- 可复现验收方式与已知限制。

架构变化涉及重要取舍时，同时新增 ADR。实现完成但未验收时标为“已实现，待验收”；不能用代码存在代替运行验证。
