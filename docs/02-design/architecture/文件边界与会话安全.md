# 文件边界与会话安全：本批实现及验收范围

2026-09-08。本批新增 W12（Windows 29 项）和 W13（34 项）。

## 文件与任务目录

路径由 shared/node 统一解析实际位置；不存在的文件先解析已有父目录。Windows 比较归一大小写，拒绝设备路径、数据流及盘符相对路径。失效链接、无法解析的路径不放行。权限引擎与文件工具共用此规则，授权记录绑定解析后的目标。递归搜索跳过符号链接，避免遍历跳出授权目录。

文件引用、附件目录均检查实际路径。成员不能指定临时任务目录，正式任务使用所属项目目录。管理员创建界外目录也默认被拒，仅显式配置 WORKPIVOT_ALLOW_EXTERNAL_DIRECTORIES=1 才允许。

命令环境按白名单重建，剔除应用密钥、令牌及 NODE_OPTIONS；只显式注入文档库 NODE_PATH。Word/Excel/PPT 回归通过。临时任务回收同样用真实路径判断，并禁止回收整个临时根目录。

这不是操作系统级沙箱：检查与实际文件访问间仍存在竞争窗口；同一系统账户执行的脚本可能读取其可访问的数据。旧默认项目绑定工作区根目录，可能覆盖嵌套私有项目与临时目录，尚须收敛共享布局及执行身份。项目记忆 API 的只读规则也不能替代执行层治理。RL2-06 整体验收未完成。

## 会话与初始化

新会话默认 24 小时，WORKPIVOT_SESSION_TTL_HOURS 可配置正数且最大 720 小时。退出撤销当前令牌，改密撤销全部旧令牌；后台新增撤销登录按钮，同时停止该用户所属的运行任务。旧版无 expiresAt 的会话升级后需重新登录；启动和认证请求清理过期会话。

登录/注册按来源地址每分钟 60 次、来源地址与用户名组合每分钟 10 次限速，返回 429 和等待提示，不持久锁定账户。目前不信任转发请求头，反向代理后的用户可能共享来源配额，部署验收需检查此限制。

对外监听时，首次启动必须配置至少 24 字符的 WORKPIVOT_ADMIN_INIT_TOKEN；首次注册必须提交对应凭据。注册完成后关闭首管理员入口。

## 存储和密钥

JSON 主文件正常则读取；损坏时验证备份，成功后保存损坏原件并恢复主文件。主备都损坏时明确报错，后续读取不会归零。账户结构为空或非法同样视作损坏，启动前检查，运行期状态接口返回 503。默认值复制返回，避免修改共享默认对象导致跨请求状态污染。

账户、个人记忆、项目记忆和计划写入走原子存储及一代备份；通知走统一追加入口。令牌文件不自动生成历史备份，减少撤销后恢复旧令牌的风险；恢复完整历史快照后仍必须清除所有旧会话。

服务端使用 AES-256-GCM，主密钥为 WORKPIVOT_SECRET_KEY 的 64 位十六进制文本。每次加密使用随机 nonce，校验认证标签；缺密钥、格式错误、密文篡改或密钥不匹配时失败。启动验证并迁移供应商主文件与备份中的旧 b64 密钥。主密钥必须独立备份；更换环境变量不等于密钥轮换。

桌面继续使用系统 safeStorage，不可用时不再降级写 b64。仅合成数据评测或显式本机开发允许 WORKPIVOT_INSECURE_SECRETS=1。
