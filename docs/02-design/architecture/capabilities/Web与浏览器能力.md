# Web 与浏览器能力

| 项 | 值 |
| --- | --- |
| 状态 | ✅ 搜索、静态读取、浏览器操作和共享页面已实现 |
| 适用范围 | 普通对话、自动化、共享浏览器与网页截图 |
| 安全前提 | 完整 URL 授权、公网地址校验、DNS 固定连接、不可信内容隔离 |
| 关联 | [任务授权与安全边界](../security/任务授权与安全边界.md) |

## 1. 能力分工

| 工具 | 职责 | 不负责 |
| --- | --- | --- |
| `web_search` | 返回标题、链接和摘要 | 读取完整正文 |
| `web_fetch` | 读取公开 GET 页面、文本或 JSON | 执行页面脚本、登录、表单提交 |
| `browser_visit` | 动态页面渲染、有限点击/滚动、截图 | 任意 JavaScript、持久登录、下载 |
| 共享浏览器 | 用户与 Agent 操作同一任务页面 | 绕过当前任务和页面授权 |

检索与正文分开可以控制上下文大小，也便于区分搜索结果摘要和实际引用原文。

## 2. 搜索

支持 Brave Search API 与自托管 SearXNG：

```text
web_search { query, count? } → [{ title, url, snippet }]
```

只保留无凭据的公网 HTTP(S) 链接，过滤内网、回环、无点主机和畸形地址，按 URL 去重。未配置搜索服务时工具不出现；配置非法时服务启动失败，避免每轮静默报错。

搜索词可能包含用户资料，调用前应提示不要把敏感内容写入查询；当前没有强制的敏感数据分类器。

## 3. 静态网页读取

`web_fetch` 在服务端执行 HTTP GET，使用 Readability 提取文章，失败时回退 DOM 文本。返回标题、正文、链接、最终来源、截断状态和页面类型。

安全要求：

- 只允许公网 HTTP(S) 和标准端口。
- 解析 DNS 后固定连接目标，拒绝私网、回环和保留地址。
- 每一次重定向都重新校验；普通对话跨来源跳转需要重新确认。
- 禁止非 GET、WebSocket、凭据 URL 和页面脚本。
- 返回内容始终标记为外部不可信数据。

## 4. 浏览器与共享页面

浏览器服务使用独立 Playwright/Chromium，不持有业务数据库、用户文件卷或 Docker socket。每次自动化调用新建上下文；共享页面按账号和任务建立独立会话。

共享浏览器支持：

- 地址栏、前进、后退、刷新和视口调整；
- 点击、滚动、键盘、粘贴与实时截图；
- 用户和 Agent 串行操作，忙碌时显示状态；
- 刷新重连、空闲关闭、服务重启释放；
- 不混用不同账号或任务的 Cookie 与上下文。

AI 默认读取当前页面；带 URL 导航时仍需授权。页面切换会改变操作目标，因此授权必须绑定页面代次，执行前复核。

## 5. 授权与网络边界

普通对话和手动浏览器只允许用户确认过的完整 URL，路径和查询参数参与匹配。未授权跳转或子资源返回受阻地址，用户可逐项允许或重新加载。

自动化使用计划快照中的 `webUrls`：

- 最多 20 个完整 HTTP/HTTPS 地址；
- 不支持域名通配；
- 旧 `webOrigins` 不授予权限，必须迁移后重新确认；
- 每次请求前后校验租约、撤销和来源版本；
- 离线计划不受影响。

域名白名单只限制目的地，不能证明资料没有外传。页面填写、查询参数或点击携带本地资料时需要独立的数据发送授权。

## 6. 失败与恢复

| 场景 | 行为 |
| --- | --- |
| DNS 解析到私网 | 拒绝，不发起连接 |
| 重定向到未授权来源 | 停止并返回待确认地址 |
| 浏览器服务未配置 | 不提供 `browser_visit`，明确依赖不可用 |
| 页面操作后目标变化 | 原动作授权失效，重新确认 |
| 网络或渲染失败 | 保留错误与来源，不伪造正文或成功截图 |
| 自动化取消 | 终止后续请求，不发布暂存截图 |

## 7. 已知限制

- 搜索提供商在部分网络环境可能无法访问外网引擎，需要出口代理或 API Key。
- 不持久化 Cookie，不支持任意网站登录、验证码专用接管和内网系统。
- 浏览器资源占用高，部署需单独容量与健康检查。
- 搜索结果缓存、配额计数和内容分类尚未完整实现。
- 当前验证不等于所有商业网站的兼容性与反自动化策略适配。
