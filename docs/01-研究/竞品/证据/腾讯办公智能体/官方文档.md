## 2. 产品定位与任务模型

**官方定位**：「腾讯出品的全场景 AI 办公工作台」，工作流 = **说出要求 → 开始执行任务 → 交付完整成果**。与传统 AI 对话的四点差异：实际执行任务（非建议）、自动操作本地文件、多步骤复杂任务、交付可验收结果（非文字回复）。

### 创建任务四步流程（官方操作口径）

1. **描述任务**：一句话自然语言（示例：销售数据→图表分析报告；整理 Downloads 图片按日期分类；会议纪要→PPT；简历→信息表格；行业调研→报告）
2. **选择工作空间**（可选）：输入框左下角指定，agent 基于该目录读写；不选则用默认目录
3. **添加上下文**（可选）：**@ 引用**文件/文档/规则、粘贴截图（Ctrl/Cmd+V）、上传/拖拽文件；建议补四类信息——目标、输入、输出格式（Word/Excel/PPT）、约束（风格/字数/截止时间）
4. **任务创建成功**：左侧任务列表 + 中部对话区（执行过程可见）+ 右侧**结果区**（产物/全部文件/变更/预览）；可继续补充消息或**并行创建其他任务**

界面为三栏结构（任务列表 / 对话区 / 结果区），与逆向看到的 artifact-index（产物索引）、「任务=对话+工作空间」的存储设计一一对应。

## 3. 核心功能官方说明

### 3.1 专家中心（逆向印证：extension-system §4）

- 官方定义：专家是**「角色切换」**机制——「以**人设 + 方法论 + 工具链**让 WorkBuddy 用特定领域专家身份执行任务」；专家团是**「协作执行」**——团长自动拆解、**并行执行**、整合交付
- 两板块：**专家中心**（按行业分类浏览官方专家/专家团）+ **我的专家**（用户创建自己的专家并分享）
- 定位口诀（官方）：**「Skill 是能力；专家是能力+经验；专家团是多位专家+协作流程」**
- 操作：浏览卡片（能力/擅长领域/任务示例）→ 点「召唤专家/专家团」→ 进入对话 → 描述任务
- 成本：专家团积分消耗约为单专家 **3–5 倍**
- 安全边界：专家不主动获取系统权限；配备 Skill/MCP 后才在授权下间接访问文件/外部服务

### 3.2 技能市场（逆向印证：extension-system §5）

- 技能本质：**封装可执行脚本与工作流**，让 AI 在授权下执行具体动作（发邮件、查股价、读写文件、调第三方 API）
- 安装三方式（点「添加技能」）：**上传技能**（本地技能包，导入后自动配置）/ **查找技能**（输任务描述自动找）/ **创建技能**（输任务描述自动生成）
- 启用/关闭：已装技能可随时开关（不卸载），关闭后不进入对话调用范围；官方建议**仅启用当前任务所需技能**，减少干扰与误调用
- 安全提示（官方明确）：非官方 Skill 可能存在**提示词注入、越权访问、后门**风险；技能动作以用户本人身份执行；部分 Skill 会把输入发往第三方

### 3.3 连接器（逆向印证：extension-system §6）

- 技术形态官方确认两类：**「MCP + CLI（标准化协议）」和「Skill + CLI（内置脚本）」**——与逆向发现（远程 MCP 注册 + 本地聚合代理）一致
- 已支持：QQ 邮箱、腾讯乐享、腾讯文档、腾讯会议、TAPD、腾讯网盘；**自定义连接器 = 安装自定义 MCP 服务**
- 授权流程（以 QQ 邮箱为例）：卡片 + → 跳转授权页扫码 → 手机端确认权限范围（账号信息/读近一个月邮件/代发邮件/可选删除）→ 同意 → 卡片绿点 + 启用开关；解绑一键恢复
- 权限原则：**每个连接器独立授权、不主动定时抓取、不超出用户已有权限**；连接器自身读写不耗积分，AI 理解汇总外部数据时耗积分

### 3.4 记忆（逆向印证：technical-analysis §5）

- 官方口径四类记忆内容：**事实信息、偏好习惯、人物关系、近期跟进事项**
- 形成机制：模型从会话自动抽取；**「每晚整理当天会话」**，记忆摘要每晚重新生成（对应逆向发现的按日记忆文件）
- 使用方式：**「注入系统提示词作为上下文」**（对应 memorySelector 子代理检索注入）
- 用户控制（设置→记忆）：查看 / 编辑（对话式告诉它记什么忘什么）/ 删除（单条或清空）/ **一键关闭整个功能** / **导入**（把其他 AI 产品的记忆摘要粘贴进来）
- 计费：**记忆提取由 WorkBuddy 自费完成**，不耗用户积分

### 3.5 权限模式与沙箱（逆向印证：technical-analysis §7）

- 权限模式仅两种：**默认权限**（工作空间内高效执行，高风险操作需确认）与**完全访问权限**（关闭二次确认），新建任务输入框下方下拉切换
- 沙箱三层保护：**沙箱执行**（命令优先沙箱内跑，被拦截后按风险决定是否确认）、**删除保护**（安全删除/回收站——对应逆向发现的 vendor/genie-trash）、**文件备份**（改文件前存备份，目前仅 Windows——对应逆向发现的 file-history 快照）
- 默认权限确认触发：写受保护/敏感路径、删除重要内容、执行脚本/命令/外部程序、网络访问或敏感能力命中安全中心规则
- 官方风险观：静态脚本分析不足（嵌套调用、运行时动态路径、参数差异、外部程序行为不可预判），确认弹窗要看**操作内容/影响范围/执行理由**三要素

### 3.6 项目（团队协作层，逆向未见——云端能力）

- 结构：**「项目 + 任务」两层**；项目把**指令、连接器、专家、技能包**统一配置，**任务创建时配置自动注入**（无需重复设置）
- 任务 = 项目成员在项目中的会话，**一个任务对应一个对话和一个工作空间**；支持**分享 / 转交 / 多人协作**三种协作；转交时自动打包**任务产物 + 进度摘要 + 自定义字段（标题/描述/处理人/状态/截止日期）+ 附件**，接收方带完整上下文继续
- **项目资产库**：统一文件管理（手动上传 + 任务产物保存），内容**以 RAG 形式注入任务上下文**，也可 read-file 读取；默认 5GB（依托腾讯网盘）；支持文档/表格/PPT/PDF/图片/音视频/链接
- 连接器授权分**公共授权**（管理员配置一次全员共用票据）与**个人授权**（票据不共享仅存本地）；**协作任务中个人授权连接器全部禁用**
- 项目动态三类：与我有关 / 成员动态 / 自动化通知；自动化当前为**个人级**（仅创建者可见）
- 建项目可**从模板**预设预填

### 3.7 资料库 Library（逆向印证：skill-library 插件）

- 定位：「**人和 Agent 共同的产物存放地**」，从「用完即散落」升级为「沉淀、管理、流转协同」
- 两区域：我的文档 / 团队空间；三大子能力：**内容管理**（统一目录树，任务中直接读写）、**多人多 Agent 协作**（团队空间权限、MD 审阅与 AI 修订、多人协同编辑 HTML）、**轻量发布**（本地 HTML 发布为在线链接 workbuddy.link；HTML+CSV 搭轻应用）
- 特色机制：**MD 定叙事 / CSV 唯一数据源 / HTML 管呈现**，三者互相引用，「改一处、处处生效」；Agent 对 MD 的修改以**待确认状态**呈现，接受后才写入
- Agent 权限与当前用户一致（同权限原则）；办公文件存腾讯网盘，MD/CSV/HTML 存 WorkBuddy 云端

### 3.8 助理（远程遥控器，逆向印证：claw 通道配置）

- 定位：**远程控制功能**——手机 IM 发消息 → 触发家里/公司电脑上的 WorkBuddy 执行 → 结果回传手机
- 与普通任务差异：**固定助理专属文件夹**（不可指定工作目录）、**单一会话**（远程指令集中处理）、**完整对话历史不可清空**
- 六渠道：微信助理（推荐）、微信客服号、企微、QQ 机器人、飞书、钉钉
- 安全：绑定身份+灵活换绑；**每条远程指令多层来源校验**；文件删除/系统配置修改/批准命令执行等**高风险任务需确认**后才执行
- 电脑需保持开机运行 WorkBuddy

### 3.9 自动化（逆向印证：CronCreate/CronList 工具 + ScheduledTasks 特性）

- 配置项：名称、工作空间（默认分配 automation-xxxx 空间）、提示词、**模型和技能**、定时规则（频率+生效日期区间）、**推送到小程序**
- **配置保存在本地客户端**，触发时以当前登录身份发起 Agent 任务；支持任务模板（新闻推送/周报/体检预约/学习计划）
- 限制：受频率/最大执行时长/系统并发控制；文件访问限于指定工作目录；第三方凭证仅用已授权的 MCP/连接器/OAuth 凭证
- 官方建议：先低频试运行再放量；对文件改动/对外发送保留可追溯日志

## 4. 企业版与私有化（重点）

> 说明：企业版文档挂在 CodeBuddy 企业版（copilot.tencent.com 控制台）下，同一控制台同时管理 IDE 插件与 WorkBuddy 客户端（「客户端获取」可下载全部客户端）。

### 4.1 版本与定价（官方）

| 维度 | SaaS 企业版 | 专有云企业版 |
|------|-------------|--------------|
| 部署 | 腾讯云共享 VPC | 腾讯云专享 VPC，**支持客户自有 IDC 完全离线部署** |
| 价格 | **198 元/人/月**（2,376 元/人/年），1 席起 | **316 元/人/月**（3,792 元/人/年），100 席起 |
| 用量 | 2000 积分/人/月，团队共享，对话不限频 | 同左 |
| 专属能力 | — | 专属网络访问、专属企业插件、**国产化显卡/服务器（信创）**、基于企业代码库的模型微调 |

### 4.2 私有化（专有云）开通流程（官方九步）

1. 官网/企业后台购买页发起专享版新购（企业名称、企业 ID、超管手机号）
2. 购买成功后**约 20 分钟自动部署**，超管手机号登录官网
3. 首次登录设置超管初始密码，进入企业域名管理后台
4. **「打包客户端」**：企业设置-基础设置-产品信息填写后一键打包（企业定制客户端）
5. 录入成员（手动/批量导入）
6. 逐个或**批量开启插件授权**
7. 「客户端获取」下载专用客户端
8. 分享下载链接给成员
9. 成员登录使用

> 技术细节（硬件/端口/网络要求）官方文档未公开，需售前获取——这本身是个信息点：**私有化技术门槛被隐藏在售前环节**。

### 4.3 管理后台能力清单（企业版）

账号与组织：企业管理员、企业微信集成、飞书集成、成员管理
能力治理：**模型管理、模型部署管理、知识库/知识库管理、Playbook、Skill 管理、专家管理、自定义指令、Connector 管理、企业智能体配置**
安全合规：**IP 白名单、日志管理**
度量：研效度量

### 4.4 模型部署管理（企业自添加模型）

- 两类模型：**内置官方模型**（不可启停/编辑/删除）+ **企业自添加模型**（自定义部署）
- 配置流程：管理后台 → 企业设置 → 模型设置 → 新建模型 → 填**模型名称、API_KEY、模型部署地址**（OpenAI 兼容，从模型服务商获取）→ **测试连通** → 创建（默认关闭）→ 启用并设置**用户可见范围** → 客户端/IDE 端即可切换使用
- 与逆向印证：本机 `models.json`（用户级自配模型）+ selfhosted 产品形态（仅内置 codewise-chat）+ 企业级模型管理（管理员统一下发）构成**三层模型配置体系**：企业级 → 用户级 → 内置

## 5. 积分计费设计（官方口径汇总）

| 行为 | 是否耗积分 |
|------|-----------|
| 对话/任务执行 | 耗（按模型档位 x0.01~x5 credits，见 product.json） |
| 专家团 | 单专家的 3–5 倍 |
| **记忆提取（每晚整理）** | **不耗（官方自费）** |
| 连接器自身读写 | 不耗；AI 理解/汇总外部数据耗 |
| 资料库存储/检索/手动编辑 | 不耗；AI 加工/修订耗（按发起者扣） |
| 自动化 | 视任务复杂度（提醒类低，巡检/汇总高） |

## 7. 对 WorkPivot 的新增启示（本文档新增，非重复前述文档）

1. **「项目」层是多企业协作的关键设计**：项目级「指令+连接器+专家+技能」四件套配置自动注入任务 = 企业管理员的治理抓手；**公共授权/个人授权分离 + 协作场景禁用个人授权**是权限模型的精华细节，WorkPivot 的多租户设计应直接吸收
2. **任务转交 = 上下文打包协议**（产物+进度摘要+自定义字段+附件），团队协作场景值得复用
3. **私有化交付路径参考**：购买→自动部署（20 分钟）→超管初始化→**打包企业定制客户端**→批量导入成员授权→链接分发——这条流程就是 WorkPivot releases/ 目录规范对应的实际交付场景
4. **计费边界设计**：记忆提取自费、连接器裸读写免费、AI 加工收费——按「AI 参与度」而非「功能开关」计费，用户感知更公平
5. **资料库三载体（MD/CSV/HTML）联动**与轻量发布（workbuddy.link）是把 agent 产物变成「可继续演进资产」的关键创新，值得作为 WorkPivot 知识库功能的对标
6. **官方文档站结构 = 产品功能地图**，11 个实践案例 + 10 个零成本 Skill 精选本身是运营内容（教程即获客），WorkPivot 需要规划同等位置的「实践案例」内容体系

## 8. 官方文档 vs 本机逆向：印证对照

| 主题 | 官方口径 | 逆向证据 | 一致性 |
|------|----------|----------|--------|
