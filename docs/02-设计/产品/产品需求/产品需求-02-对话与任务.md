## 1. 背景与目标

对话与任务是产品的**工作主场**（需求清单 F 模块定位：agent 效果核心层）。本 PRD 定义：用户如何组织工作（项目→任务）、如何下指令与跟进（对话+过程主线）、如何接收成果（预览/版本链/下载）、以及 agent 效果核心层的全部界面呈现（核验/收尾/续跑/循环检测/授权）。

**设计总则**（已确认决策的汇总）：
1. 三栏 = 左（新对话+项目树+资产入口+用户区块）｜中（交流对话区）｜右（成果预览，专职）
2. 过程展示 = **中文叙事主线**（获取了什么数据→做了什么处理→得出什么结论），细节折叠，全量转写可回看
3. 任务 = 对话 + 工作目录；项目 = 文件夹（多任务共享项目记忆）
4. 弱网降级整段渲染；断线任务照跑、重连接回
5. 一切等待用户的时刻（授权/提问/审批）必须显性呈现，禁止静默卡死

## 2. 核心对象与状态机

### 2.1 层级：项目 → 任务

```
项目 Project（=文件夹，含项目记忆 E02、共享素材）
 └─ 任务 Task（=对话+工作目录绑定，产物落盘 B01/B02）
```

- 项目可嵌套？**不嵌套**（单层项目列表，路径可自定义子目录）
- 任务归属唯一项目；「未分组任务」挂在默认项目下

### 2.2 任务状态机

```
                 ┌──────────► 等待用户（授权/提问/审批）──用户响应──┐
                 │                                              ▼
创建 ──► 运行中 ─┤                                          运行中 ──► 完成
 （草稿）        │                                              ▲
                 ├──────────► 已中断（崩溃/重启/断流超时）─继续─┘
                 │                       │
                 └──手动停止──► 已停止 ◄──┘（停止即终态，可"从此继续"转为新运行）
                 任何运行态 ──► 失败（重试用尽/预算外错误，F03 收尾后置）
```

| 状态 | 触发 | UI 表现 |
|------|------|---------|
| 草稿 | 新建向导未提交 | 左栏灰字；不出现在对话区 |
| 运行中 | 提交/继续 | 左栏绿点；中栏实时主线；顶部「停止」按钮可用 |
| 等待用户 | I08 界外授权/结构化提问/工具审批（I06） | **左栏黄点+系统通知（A06）+对话区置顶操作卡**；超过 30 分钟无响应任务转「已中断（等待超时）」 |
| 已中断 | 进程退出/断流>10 分钟/等待超时 | 左栏黄点；对话区顶部横条「任务已中断——继续 / 查看进度」 |
| 完成 | 模型收尾+成果核验（F02）通过 | 左栏灰点；完成通知；成果卡置顶 |
| 失败 | F03 收尾后判定 | 左栏红点；失败原因+收尾交代三要素 |
| 已停止 | 用户点停止 | 灰点；本条消息后停止，不再计费 |

**状态并发**：同一任务单执行流（不支持同任务并行两轮）；用户在「运行中」发新消息 → 入队（排队气泡显示「已排队，当前任务完成后处理」）。

## 3. 左栏规格

### 3.1 结构（自上而下）

1. **「新对话」主按钮**（品牌蓝，通栏）→ 打开新建任务向导（§5）
2. **项目区**：
   - 项目头（名称 + 任务计数 + hover「新建任务」快捷）——点击展开/收起
   - 项目名右侧上下文菜单（右键/hover ⋯）：重命名 / 更换目录（单机）/ 项目记忆 / 删除项目（任务不删，移入未分组）
   - 任务行：标题（自动取首句/可改）+ 状态点；hover 显示时间；当前任务高亮
   - 项目尾「在本项目新建任务」快捷行
   - **项目记忆提示条**（有记忆时）：「项目记忆已积累 · 任务间共享上下文」，点击 → 项目记忆面板（PRD-05）
   - 「新建项目」入口（单机形态需选目录；服务端形态仅填名称）
3. **资产区**：技能与工具 / agent.md 编辑 / 项目记忆（PRD-03/PRD-05 承载界面，本栏仅入口）
4. **用户区块**（PRD-01 已定稿，不重复）

### 3.2 任务排序与搜索

- 默认排序：运行中/等待用户置顶，其余按最近活动时间倒序
- 项目内任务数 >20 时显示项目内搜索框；全局搜索（A05，P2）

## 4. 中栏规格

### 4.1 顶部信息条

`[项目名 · 共享项目记忆] ｜ 工作目录（服务端形态显示 server:// 路径，单机显示本地路径，点击展开目录树面板）｜ 专家：XX ｜ 模型：XX（推荐）`

- 专家/模型点击可改（模型下拉见 4.4；改后下一轮生效 C04）
- 等待用户/中断状态时，信息条下方追加状态横条（操作按钮）

### 4.2 对话流与过程主线（A03 已定稿方向的落地规格）

**用户消息**：右侧蓝底气泡；@文件 引用显示为文件芯片（名称+类型，点击在右栏打开）；上传素材显示附件卡。

**AI 回复 = 主线 + 卡片 + 折叠层**：

| 组件 | 规则 |
|------|------|
| **思考过程（2026-08-29 用户确认新增）** | AI 每轮的推理/思考内容以**可折叠的「思考」块**呈现在阶段条目上方：运行中实时流式展开（默认展开最新一条，历史自动折叠为一行摘要「已思考 Ns · 点击展开」）；内容=模型 reasoning 输出的中文呈现；不占结论层视觉——结论永远在阶段条目与结论卡，思考块仅过程参考；关闭思考显示的开关在输入区底栏 |
| 阶段条目（主线） | 每计划阶段一条，格式：**动作+对象+（结果）**，中文叙事三段式（获取→处理→结论）；运行中的阶段显示进度（如 3/5）与取消线能力 |
| 关键结论卡 | 黄底卡片，含数字/决策；数字必须与最终成果一致（F02 核验联动） |
| 异常前置卡 | 界外授权/等待审批/提问——**置顶悬浮于对话流**，同时系统通知；不沉入历史流 |
| 工具明细（折叠） | 阶段条目下可展开：工具名（英文标识仅在此层出现）、参数摘要、结果原文、耗时；默认收起 |
| 来源列表 | 回复底部：「本回合参考来源」——真实访问记录（G01/G03），每条=标题+域名；抓取失败不列入；点击右栏打开 |
| 中间产物引用 | 阶段叙述中提到的文件（如「分析底稿.docx」）渲染为文件链接，点击右栏预览 |

**流式渲染**：正常网络逐段流式；**弱网（RTT>800ms）自动切换整段刷新**（A02）；主线阶段切换时有轻微动效。

### 4.3 收尾与核验呈现（F02/F03 界面化）

- **强制收尾卡**（任务完成时置顶）：三要素——完成了什么（一句话）/ 产出文件清单（卡片，点击右栏）/ 下次从哪继续（如有未竟事项）
- **核验失败重做**：主线显示「核验未通过：声明的文件 XX 不存在——已要求重做（1/2）」；两次失败后终态失败并如实交代
- **循环检测提示**（F05）：连续雷同时主线插入「检测到重复操作，已提醒 AI 更换思路」；拦截时显示「已拦截重复执行」

### 4.4 输入区

```
[+ 附件/上传素材] [输入框：输入消息，@ 引用文件，/ 使用技能…] [发送]
底栏：🛡权限档位（当前档，点击切换四档菜单）｜🔔通知状态｜模型选择器（当前模型▲）
```

- **@ 引用**：输入 @ 弹文件选择浮层（当前工作区文件优先+搜索；服务端形态含「上传本地素材」入口，上传后即工作区文件）
- **/ 技能**：输入 / 弹技能列表（名称+描述，仅用户可触发型含「仅手动」标记）
- **权限档位菜单**：四档单选+当前档说明一句话；切换即时生效（下一工具调用起）
- **模型选择器**：列表=管理员开放范围；每项=名称+说明+「推荐」标（按任务类型 C04）+健康标（连挂标红）；切换确认提示「下一轮起生效」
- 发送规则：运行中发送=排队（气泡提示）；草稿态 Enter 直接发送

### 4.5 转写查看器（F01 回看）

对话区右上「历史记录」入口 → 全量转写只读视图（每条消息/工具调用原文/隐藏注入标注）；按轮次分组；导出 Markdown。**默认入口折叠**，标注「排查与复盘用」。

## 5. 新建任务向导（四步，居中弹窗）

**Step 1 描述任务**（必填）：多行输入；粘贴图片自动附为素材；底部示例提示（3 个场景化示例轮换）
**Step 2 选择项目与目录**：下拉选项目（默认当前项目/最近项目）+ 新建项目快捷；单机形态显示该项目目录路径（可改）；服务端形态显示 server:// 路径（不可改）
**Step 3 添加上下文**（可选）：@文件 多选 / 拖拽上传区 / 截图粘贴
**Step 4 确认开始**：摘要卡（项目/专家/模型（含推荐标）/上下文数）——专家与模型此时可改（专家下拉含「通用助手」默认；模型按 C04 规则预选并标注推荐）

- 每步可回退；Step 1 有内容即可直接「开始」（2-4 全默认）——**快路径两步完成**（输入+开始）
- 提交 → 任务进入左栏 + 中栏切换到新任务对话

## 6. 右栏规格（成果预览，专职）

### 6.1 结构

- 头部：当前预览文件名 + **下载按钮**（单文件下载；「全部下载」打包 zip——B01 服务端形态确认项）+ 历史版本入口
- 主体：预览区（H05/A04：docx/xlsx/pptx/pdf/图片/HTML/Markdown；不支持格式→「下载后本地打开」提示）
- 空态：显示本任务产物文件卡片列表（点击预览）

### 6.2 版本链（B02）

同标题交付物聚合：v1.0→v1.5 按时间排列，当前版高亮；每版可预览/下载/「设为当前」；文件名不符合版本模式的按独立文件展示（不强行聚合）。

### 6.3 历史版本与恢复（B03）

文件菜单「历史版本」→ 快照列表（时间/大小/来源「AI 修改前/删除前」）→ 预览某版本 / 一键恢复（恢复为新版本，不覆盖）。

## 7. 等待用户的四类弹窗/卡片

| 类型 | 触发 | 呈现 | 选项 |
|------|------|------|------|
| **界外访问授权**（I08） | 读写工作目录外路径 | 对话区置顶卡+系统通知：显示目标路径/操作类型/原因（AI 填写） | 仅此次 / 本会话记住 / 永久加白名单 / 拒绝（拒绝后 AI 收到拒绝原因继续换路） |
| 结构化提问 | AI 主动提问（选项式） | 对话区置顶卡：问题+选项（单/多选）+「其他」自填 | 选中即回传 |
| 工具审批（I06） | 外部 MCP 工具首次/敏感调用 | 置顶卡：工具名/参数摘要/风险说明 | 允许（本会话记住同类）/ 拒绝 |
| 敏感操作确认 | 删除/覆盖等多步不可逆 | 模态确认框（更强打断）：影响清单 | 确认 / 取消 |

通用规则：置顶卡同一时刻最多一张（排队）；30 分钟无响应 → 任务转中断+通知；所有决策入审计（I03）。

## 8. 本地缓存与快速启动（2026-08-29 用户确认新增）

- **原则**：服务端=权威源（J02 拓扑二）；**本地=缓存层**——启动不依赖网络拉全量，秒开。
- **本地缓存内容**（`~/.workpivot/cache/`，桌面客户端）：项目/任务列表与状态、最近 20 个任务的转写尾部（主线渲染所需）、成果文件索引（名称/版本链/大小，不含文件体）、用户设置副本。
- **启动流程**：① 读本地缓存立即渲染界面（<500ms）→ ② 后台与服务端增量同步（差量拉取，按任务 updated_at）→ ③ 冲突以服务端为准并刷新对应视图。
- **回放与离线查看**：缓存命中的任务可离线查看主线与转写（只读）；文件预览需在线（或已缓存文件）。
- **缓存治理**：LRU 上限（默认 500MB，可调）；登出可选清缓存（企业合规：换人用机场景默认提示清理）。
- **验收**：断网状态启动应用 <2s 呈现完整任务列表与最近任务主线；联网后 5s 内完成增量同步无感刷新。

## 9. 中断、续跑与并发呈现（F04）

- **中断横条**：「任务已中断——[继续] [查看进度]」，AI 续跑时主线首条显示「从断点继续：已完成 X/Y 步」
- 断线重连：主线无感接回（重连横条短暂提示 2s 消失）
- 并发上限提示：企业并发满时新建任务进入排队（横条「排队中，前方 N 个任务；预计等待约 X 分钟」——按近 30 分钟平均任务时长估算）

## 10. 定时任务界面（F06）

入口：左栏「自动化」（资产区下）。列表页：名称/计划（cron 转中文「每天 09:00」）/下次执行/最近结果/启停/编辑；新建表单：名称+提示词（多行）+计划（预设模板：每天/每周/每月/cron 高级）+推送通知开关（A06）；执行历史页（每次运行的入口任务+结果摘要）；**错过补跑**标记（「补跑」标签）。定时任务产生的会话在项目树中以任务形态出现（标「定时」）。

## 11. 数据模型（任务域）

```
projects: id / name / dir_path(单机) / owner_uid / created_at / archived_at
tasks: id / project_id / title / status / expert_id / model_id / created_by
       / created_at / updated_at / last_activity_at / progress_file(PROGRESS.md 路径)
task_queue: task_id / queued_message / enqueued_at
task_runs: id / task_id / status / started_at / ended_at / finish_reason(normal|forced|stopped|failed)
           / artifacts_json(核验通过的产物清单) / usage_json
scheduled_jobs: id / name / prompt / cron / notify / enabled / next_run_at / last_run_at
```

转写与会话事件见 F01（JSONL，按 task 存储于 `data/tasks/{id}/transcript.jsonl`）。

## 12. 异常与边界场景

| # | 场景 | 处理 |
|---|------|------|
| 1 | 任务运行中用户删除该项目 | 二次确认「项目下 N 个运行中任务将转未分组」；任务不中断 |
| 2 | 多端同时打开同一任务 | 双向同步主线（服务端广播）；两端都能发消息（服务端排队串行） |
| 3 | 弱网下上传大素材失败 | 分片重试；失败保留本地缓存待重传提示 |
| 4 | 版本链聚合误判（同名不同物） | 用户可「取消聚合」拆为独立文件 |
| 5 | 排队任务在排队期间会话过期 | 任务照常执行（服务端）；用户重登后接回 |
| 6 | AI 在主线叙述里给出与结论卡矛盾的数字 | F02 核验以文件实际内容为准；不一致标注「以文件为准」并计 eval |
| 7 | 停止点击瞬间模型已开始下一轮 | 停止信号打断当前工具调用；已产生费用如实计入 |
| 8 | 定时任务到点时服务并发满 | 按队列顺序执行，错过的在空位后补跑（F06 补跑标记） |

## 13. 验收清单

- [ ] 新建任务快路径（输入+开始）两步完成；四步向导全字段可回退
- [ ] 主线条目 ≤ 计划阶段数；每条含「获取/处理/结论」中文三段式；英文工具名仅折叠层可见
- [ ] 结论卡数字与成果文件一致（抽测 10 例）
- [ ] 四类等待卡片呈现+通知+30 分钟超时转中断
- [ ] 界外授权四选项+白名单即时生效+拒绝后 AI 换路
- [ ] 断网 60s 重连接回无丢失；弱网（模拟 RTT>800ms）自动整段渲染
- [ ] kill 进程重启后中断横条+继续断点完成（eval）；排队提示与估算
- [ ] 版本链聚合/拆分；历史版本恢复为新版本
- [ ] 右栏五类格式预览+单文件/打包下载（服务端形态）
- [ ] 定时任务：创建/中文计划显示/补跑标记/结果通知
- [ ] 转写查看器全量只读+导出 Markdown
- [ ] 思考块：运行中实时流式、历史折叠为一行、可全局关闭显示
- [ ] 断网启动 <2s 呈现完整列表与最近任务主线（本地缓存）；联网 5s 内增量同步

## 14. 开放问题
