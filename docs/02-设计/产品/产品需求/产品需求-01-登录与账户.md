## 1. 背景与目标

WorkPivot 是企业内部使用的私有化智能工作台，支持管理员分配账户和由管理员显式开放的试用自助注册。本 PRD 覆盖：登录、首用户管理员创建、可配置注册、首登改密、初始化引导、用户管理（后台）、OIDC 入口、修改密码和登录态管理。

**目标**：① 登录流程安全合规（企业审计标准）② 管理员管号成本最低（建号/停用/重置 30 秒完成）③ 用户开箱即用（登录后引导配好模型即可干活）。

**非目标**：无管理员控制的无限注册、自助邮件找回密码、用户修改自己的用户名、跨企业多租户。试用实例可以有界开放自助注册，并受默认日限额约束。

## 2. 用户角色

| 角色 | 来源 | 能做什么 |
|------|------|----------|
| **企业管理员** | 首个注册用户自动成为；或由管理员授予 | 用户管理、模型管理（M03）、默认 agent.md（S03）、全部后台功能 |
| 连接器管理员 | 管理员授予 | 公共连接器/Skill 配置（S01/S02/S02a）、凭据管理 |
| 普通成员 | 管理员创建、自助注册或经管理员绑定的 OIDC 身份 | 使用产品（对话/任务/个人技能/个人连接器） |
| 单机用户 | 拓扑一首个注册者 | 管理员+使用者合一 |

角色可兼任（一人多角色）。权限矩阵见 §9。

## 4. 页面详细规格

### P1 登录页

**布局**：居中卡片，logo 与账户表单；底部并排“登录 / 注册”两个按钮，不再使用一段长文字兼顾两种动作。注册入口是否显示由后台注册模式决定，已启用 OIDC 时显示对应身份入口。

**字段与校验**：

| 字段 | 规则 | 校验时机 |
|------|------|----------|
| 用户名 | 4-32 位，字母开头，字母/数字/下划线 | 失焦+提交 |
| 密码 | ≥8 位（含字母和数字为创建规则；登录仅非空） | 提交 |

**交互细节**：
- 密码框右侧「👁 显示/隐藏」切换
- 登录按钮：提交后 loading 态（防重复点击），异步验证
- Enter 键提交

**错误提示（三种场景文案）**：

| 场景 | 提示文案 | 备注 |
|------|----------|------|
| 用户名或密码错误 | 「用户名或密码不正确，还可尝试 N 次」（N≤5） | 不区分「用户不存在」与「密码错」（防用户名枚举） |
| 连续错误达 5 次 | 「失败次数过多，账号已锁定 15 分钟」 | 服务端锁定（见 §8 安全） |
| 账号已停用 | 「账号已被停用，请联系管理员」 | 停用账户即便密码正确也拒绝 |

**注册入口显示逻辑**：仅当 `users` 表为空时显示「还没有账号？注册管理员账号」链接；存在任意用户后永久隐藏（前端按登录响应的 `hasUsers` 字段控制；API 不暴露用户数）。

**OIDC 登录（当前）**：从 `/api/auth/state` 获取已启用身份源；点击后由服务端生成一次性绑定 Cookie 和 PKCE 授权地址。回调只接受精确 state、issuer、audience、nonce 和签名匹配的结果；未知外部身份进入管理员待授权列表，不按邮箱自动合并。企业微信与组织同步仍为后续适配。

### P2 注册页（首个管理员）

**进入条件**：空数据库允许首用户创建管理员；已有用户时仅当后台注册模式为 `open` 才允许自助注册，否则入口隐藏且 API 返回 403。自助注册账户使用独立的默认限额。

**字段**：

| 字段 | 规则 | 必填 |
|------|------|------|
| 用户名 | 4-32 位，字母开头，字母/数字/下划线，实时唯一性校验（此时仅 0 用户，实际是格式校验） | ✅ |
| 密码 | ≥8 位且含字母和数字；强度条实时显示（弱/中/强：长度+字符类别计分） | ✅ |
| 确认密码 | 与密码一致 | ✅ |
| 显示名称 | ≤32 字符，默认=用户名 | ❌ |

**交互**：全部校验通过才可提交；提交 → 创建 uid=1、role=admin 账户 → 自动登录 → P4 初始化引导。

### P3 强制改密页（首登）

**进入条件**：账户的 `must_change_password=true`（管理员建号默认置 true）登录成功后强制进入，不可跳过（关闭应用重开仍停留此页）。

**字段**：原密码（初始密码）/ 新密码（≥8 位含字母数字，强度条）/ 确认新密码。新密码不得与原密码相同。

**完成**：改密成功 → `must_change_password=false` → 按新流程进入（新账户 → P4 引导；否则主界面）。

### P4 初始化引导

**触发**：① 首个管理员注册后 ② 管理员新建的用户首登改密后（引导内容为「使用向」，模型配置仅对管理员角色显示）。

**内容（管理员视角，2 步）**：
- 步骤 1 模型配置：模型服务地址（OpenAI 兼容 base_url，含内网示例占位）+ API Key；**「测试连接」按钮实时验活**（C02：通过才可保存）；提示「由管理员统一配置，成员无需操作」
- 步骤 2 基础信息（可选）：企业显示名称（后台标题栏用）

**跳过**：「暂不配置，跳过」始终可用；跳过后后台模型为空时，主界面提示「尚未配置模型，请联系管理员或前往后台配置」（管理员看到的是「前往配置」按钮）。

### P5 锁屏页

**触发**：设置开启「锁屏密码」且满足超时条件（默认 30 分钟无操作）。遮盖主界面（不退出登录、任务继续跑），输入账户密码解锁。忘记密码 → 「退出登录」回登录页。

### P6 用户管理（后台）

**入口**：主界面右上角「后台管理」（仅管理员/连接器管理员可见）→ 管理后台侧栏「用户与角色」。

**列表**：列=用户名/显示名称/角色（可多个标签）/状态（启用·停用）/最近登录时间/操作。顶部搜索框（用户名+显示名称模糊）。默认按创建时间倒序。

**操作与交互**：

| 操作 | 交互 | 生效规则 |
|------|------|----------|
| 新增用户 | 弹窗：用户名/初始密码/显示名称/角色（成员·连接器管理员·企业管理员，可多选） | 创建即 `must_change_password=true`；初始密码展示一次（弹窗内「复制」按钮）供线下告知 |
| 编辑 | 弹窗：显示名称/角色（用户名不可改） | 即时生效 |
| 停用 | 二次确认：「停用后 {用户} 将在 30 秒内被强制下线，任务在服务端继续执行」 | 会话 token 加入黑名单；服务端任务不中断（F04），该用户无法发起新任务 |
| 启用 | 二次确认 | 即时 |
| 重置密码 | 二次确认 → 生成 8 位随机临时密码，**弹窗一次性展示+复制按钮**；`must_change_password=true` | 用户下次登录走 P3 |
| 批量导入 CSV | 弹窗：下载模板（列：username,display_name,role）/ 上传 / 预览校验结果（错误行标红说明）/ 确认导入 | 全部成功或全部回滚（事务）；报告「成功 N 条，失败 M 条（原因）」 |
| 企业身份（部分实现） | 管理员配置标准 OIDC 身份源；未知外部结果进入待授权列表，人工绑定到本地账号 | OIDC 基础已通过 Keycloak；企业微信与组织自动同步仍待目标环境 |

**保护规则**：① 不允许停用自己 ② 不允许停用/降级**最后一个企业管理员**（按钮置灰+提示「至少保留一名企业管理员」）。

### P7 账户未分配提示页

OIDC 登录成功但尚无本地绑定时，页面提示等待管理员授权；系统不按邮箱、姓名或手机号自动合并账号。管理员在后台显式绑定后才可签发 WorkPivot 会话。

## 5. 登录态与多端管理

| 项 | 规则 |
|----|------|
| 会话保持 | 登录成功签发会话 token（有效期 30 天）；「记住我」默认勾选——取消则 token 仅当前窗口会话有效 |
| 多端在线 | 同一账号允许多设备同时在线（服务端会话列表可查：设备/最近活跃；支持单设备强制下线——用户安全设置页） |
| 锁屏 | 用户级开关（默认关）+ 超时时间（默认 30 分钟） |
| 退出登录 | 清除本地 token；仅退出当前设备（其他端不受影响） |
| 停用与 token | 账户停用 → 全端 token 黑名单，30 秒内全部失效 |
| 密码修改 | 仅强制改密后要求重登一次；主动改密不踢其他端（多端在线决策的自然结果） |

## 6. 数据模型（账户域）

```
users:
  uid            主键
  username       唯一，4-32 位
  display_name   ≤32 字符
  password_hash  bcrypt(cost≥10)；仅 OIDC 的账户可不设置本地密码
  roles          ["admin"] / ["connector_admin"] / ["member"] 多值
  status         active | disabled
  must_change_password  bool
  external_identity    OIDC 按 issuer + subject 作用域绑定
  created_at / last_login_at / updated_at
sessions:
  token_hash(sha256) / uid / device_name / created_at / last_active_at / expires_at / revoked(bool)
```

## 7. 服务端形态差异（拓扑二）

- 同一套页面与流程（Web-ready：登录页为普通 Web 页面，浏览器直接访问）
- 多用户会话隔离由服务端 sessions 表承载（J01）；单机形态同结构存本地 SQLite
- 标准 OIDC 登录由浏览器完成授权码回调；未知身份等待管理员绑定，不自动创建成员

## 8. 安全规格

| 项 | 规则 |
|----|------|
| 密码存储 | bcrypt（cost≥10）；任何日志/审计不出现明文与 hash |
| 防爆破 | 连续失败 5 次 → 账户锁定 15 分钟（服务端计时）；锁定期间正确密码也拒绝并提示剩余时间 |
| 会话 token | 随机 ≥256bit；服务端存 sha256 hash；HTTP Only + SameSite Cookie（浏览器）/ 安全存储（桌面端走 I04） |
| 登录审计 | 登录成功/失败/锁定/停用踢线全量入 I03 审计日志（时间/用户名/来源 IP/结果） |
| 用户名枚举防护 | 「用户不存在」与「密码错误」返回同一文案（见 P1 错误提示） |
| OIDC | 严格校验签名、issuer、audience、nonce、state 和浏览器绑定；client secret 加密保存且永不回显 |

## 10. 异常与边界场景

| # | 场景 | 处理 |
|---|------|------|
| 1 | 管理员尝试停用自己 | 按钮禁用+提示 |
| 2 | 停用最后一个企业管理员 | 按钮禁用+提示「至少保留一名企业管理员」 |
| 3 | 管理员重置密码期间用户正在线 | 不踢线；用户下次登录用新密码走 P3 |
| 4 | OIDC 外部身份未绑定或账号已停用 | 不签发本地会话；显示待管理员处理或明确拒绝，不自动合并账号 |
| 5 | CSV 导入含重复用户名 | 该行报错回滚，事务性：要么全部成功要么全部失败 |
| 6 | 30 天 token 过期正赶上任务运行中 | 服务端任务不受影响（F04）；重登后接回 |
| 7 | 锁屏忘记密码 | 「退出登录」→ 登录页 → 走管理员重置流程 |
| 8 | 双拓扑：同一账号在桌面端与浏览器同时登录 | 允许（多端在线）；任务列表一致，实时流两端同时接收 |
