# 自动化独立页面与交互原型

日期：2026-10-17。状态：原型已制作，等待用户确认界面与交互；尚未开发 ST 业务接口和调度器。属于统一计划 ST-01、ST-04 的设计细化，不新增独立排期。

## 用户要求

自动化与普通任务、聊天内容分开展示，拥有独立页面。手动新增时选择具体 Skill 并设置执行要求和定时／周期规则。对话创建的自动化也进入这个页面统一管理。每个自动化以卡片面板展示是否生效，并提供修改、停用和编辑入口。

## 页面结构

1. **自动化总览**：保留应用级导航，移除普通项目任务树、聊天输入区和任务侧栏。顶部为总数、已启用、待确认、需处理统计；支持状态筛选和按计划／技能搜索。卡片展示名称、用途、Skill 固定版本、计划状态、周期、时区、下次时间、最近结果及创建来源。
2. **独立新增／编辑页**：配置执行内容、时间、运行与提醒，右侧持续预览下一次及随后两次时间。采用独立页面承载完整设置，仅最终确认使用弹窗。
3. **计划详情页**：汇总固定 Skill、时间和执行要求，下方为该计划的运行记录、失败原因及成果入口。自动化运行不挤入普通任务列表；底层可复用任务执行能力，通过来源类型和计划关联区分查询与展示。

宽屏三列卡片，中等宽度两列，窄屏一列。编辑预览在窄屏下移到表单后；应用级导航压缩。

## 创建及修改流程

手动：新增自动化 → 名称 → 已确认可用 Skill／固定版本 → 执行要求 → 输入资料和成果项目 → 指定时间／每天／每周／固定间隔 → 核对预览 → 保存为停用计划，或确认并启用。

对话：模型生成结构化草稿 → 立即出现在同一总览“待确认”分类 → 标注“对话创建” → 从对话中的入口或卡片“确认设置”进入相同编辑页 → 用户确认后启用。对话生成不会静默启用；不另设第二个管理列表。

编辑已启用计划时，旧配置在新配置确认前保持原状；确认后仅影响后续执行。当前运行仍使用自己的固定快照。保存为停用计划同时明确停用后续触发。Skill 升级不自动更新计划；切换版本重新确认。

## 字段与行为

| 区域 | 内容 |
|---|---|
| 执行内容 | 名称、Skill 及固定版本、成果项目、执行要求 |
| 输入 | 无文件、固定文件版本、限定项目与匹配规则的最新文件；不允许“最新资料”隐式读取全部项目 |
| 时间 | 指定未来时间一次、每天、每周多选星期、固定分钟／小时间隔；最短5分钟；时区；可选结束日期 |
| 运行 | 同计划不重叠，忙时最多保留一次待执行；离线后最多补跑一次或跳过 |
| 提醒 | 默认失败／需人工处理时站内提醒，可改为每次完成及失败时提醒 |
| 成果 | 每次独立保存，归属所选项目，在计划运行记录查看，不覆盖历史成果 |

“工作日”明确解释为周一至周五，不自动处理法定节假日和调休。固定间隔首轮从启用后一个完整间隔开始。高级 cron 仍保留在既有 ST 设计中，本次基础界面原型未展示；正式接入时放在高级设置并复核解析结果，不使用前端预览作为调度事实。

## 状态分离

- 计划状态：待确认、已启用、已停用、需要处理。依赖不可用或授权失效时阻止新运行，并显示具体原因和处理入口。
- 单次执行：排队、运行中、完成、失败、中断。失败不等于计划被停用；依赖问题则需阻止后续运行。
- 停用：停止后续触发，保留历史与成果。当前运行默认继续，正式版提供独立停止当前运行操作，避免含糊地同时停止多个对象。
- 到期或一次性任务完成后，正式版增加已结束状态；原型尚未模拟时间推进。
- 恢复启用再次核对时间、输入和版本；恢复备份后沿用 ST 规则默认停用，不能自动恢复授权。
