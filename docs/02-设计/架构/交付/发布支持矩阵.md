# WorkPivot 发布支持矩阵

| 项 | 值 |
| --- | --- |
| 状态 | RC.8 候选矩阵 |
| 适用版本 | `v0.3.0-rc.8` / `v0.3.0` |
| 部署形态 | 单服务器 Docker Compose |

## 支持级别

| 能力 | 级别 | 说明 |
| --- | --- | --- |
| Web 用户端 | 正式支持 | Chromium、Chrome、Edge 当前稳定版；SSE、文件上传和预览需 HTTPS |
| Web 管理端 | 正式支持 | 管理员角色；不读取成员私人正文 |
| Windows 桌面客户端 | Beta 正式支持 | 未签名便携/NSIS 包；RC.8 支持更新检查、摘要校验和打开下载制品，实际 Windows 安装器升级仍需目标机验收 |
| Android 客户端 | Beta 正式支持 | Capacitor 私有分发；RC.8 发布 1.11（versionCode 12），支持更新检查、断点续传、SHA-256/包名/版本/签名校验和系统安装确认；1.9 → 1.11 原地覆盖升级待验收 |
| 单机 PostgreSQL + pgvector | 正式支持 | schema v72；数据库和文件卷必须联合备份 |
| Docker 本地持久卷 | 正式支持 | 单节点；不支持多个应用节点直接共享 |
| OpenAI 兼容模型 | 正式支持 | 具体模型质量、上下文和计费由供应商决定 |
| Anthropic Messages 协议 | 正式支持 | 已实现协议适配和真实请求测试 |
| OIDC | 可选支持 | Keycloak 协议链路已验证；目标企业 IdP 仍需实际配置验收 |
| Office 转 PDF 预览 | 可选支持 | 需要带 LibreOffice 的隔离执行器；复杂版式不承诺像素级一致 |
| Browser / Worker / SearXNG | 可选工具 | 未配置时对应工具明确不可用，不影响基本聊天和文件功能 |
| 多 API / 多 Worker | 不支持 | 计划在 `v0.4.0` 提供 |
| 跨主机共享文件卷 | 不支持 | `v0.4.0` 使用 S3 兼容对象存储替代 |
| 自动故障转移 / 多故障域 | 不支持 | `v0.4.0` 建设高可用基础，`v0.6.0` 完成多故障域容灾 |
| Kubernetes | 不支持 | 仅在规模和运维需求明确后评估 |

## 浏览器要求

- 必须启用 JavaScript、`fetch`、`EventSource`、`crypto.randomUUID` 和 `AbortSignal`。
- 文件上传、下载和预览需要允许 Blob URL。
- 不支持 Internet Explorer、旧版 EdgeHTML 和关闭本地存储的隐私模式。
- SSE 代理必须关闭响应缓冲，并允许至少 5 分钟长连接。

## Android 要求

- Android 7.0（API 24）及以上。
- 服务端必须配置 `WORKPIVOT_MOBILE_ORIGINS=https://localhost,capacitor://localhost`。
- 必须使用 HTTPS，证书域名与连接地址一致。
- 安装包必须使用同一签名密钥升级；不能把调试签名包与发布签名包互相覆盖。
- 应用内更新已经实现版本清单、HTTPS 下载、SHA-256/包名/版本/签名校验和系统安装确认；Android 系统仍要求用户在安装器中确认。
- release 包不能依靠 `adb install --allow-downgrade` 降级；覆盖升级必须从低版本制品向高版本制品执行。

## 桌面要求

- Windows 10/11 x64。
- 解压目录不能缺少 `resources`、`locales` 或 Electron 运行文件。
- 服务器地址只允许 HTTPS；本机开发环境可显式允许回环 HTTP。

## 不支持或不在保证范围

- 应用内直接编辑 Office 文件。
- Microsoft Word/WPS 的逐像素一致性。
- 宏、嵌入对象、动画、复杂公式和所有特殊字体的无损显示。
- 未经用户确认的知识入库、记忆更新或外部副作用。
- 单机数据库成为唯一副本时不承担主机磁盘损坏的数据恢复承诺。
- 在不满足上述客户端、浏览器和网络要求时保证一致体验。
