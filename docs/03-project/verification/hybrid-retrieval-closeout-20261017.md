# SU-R2-02 混合检索与引用交付

日期：2026-10-17。已完成开发、隔离评测、真实模型和浏览器验收，并更新本机Docker。对应统一计划SU-R2-02，不扩大到OCR阶段。

## 最终行为

- 聊天的 `search_project_documents` 与任务知识检索HTTP接口共用混合链路。中文通过Intl.Segmenter提取词语，同时保留完整短语和精确编号。关键词按命中词数排序，语义按pgvector余弦距离排序，各取24条；使用等权RRF、常数60融合，按分片ID去重，最多返回8条。
- 语义候选最低相似度0.55，用于过滤弱相关片段；该默认值在本机BGE-M3固定集验证，不是跨模型通用正确率阈值。切换其他模型应重新运行质量评测。
- 外部向量请求最多等待8秒。服务未配置、暂停、未就绪或失败时返回关键词结果和明确notice；聊天工具事件旁展示检索模式。用户取消直接停止，不作为成功降级。
- 外部请求后再次按当前用户、任务所属项目和最新已解析版本过滤候选。请求期间删除资料不会把先前关键词命中回传；版本更新后旧片段不能重新进入结果。
- 工具提供 `#citation/<chunkId>` 引用。助手回答中的引用渲染为按钮，每次打开通过认证接口读取原文，显示文件名、版本、段落/页/工作表位置和字符偏移。新版本尚未解析时显示使用旧版提示；已删除、被替换或跨项目引用拒绝读取。
- 引用窗口保持稳定的渲染器身份，后台事件刷新不会意外关闭。文档正文按纯文本显示，Markdown不执行原始HTML。历史回答可能过时，失效引用不会从旧工具正文补出原文。
