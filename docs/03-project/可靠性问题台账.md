## 问题单

### A-1 ｜P0｜ 全局权限档位任何登录用户可改

- **落点**：`packages/server/src/app.ts:226`（`PUT /api/settings/tier` 无守卫）、`permissions.ts:36-44`（档位为全局单值）
- **复现步骤**：① 用 member 账号登录，前端设置面板把档位切到「完全访问」；或 `curl -X PUT /api/settings/tier -H "Authorization: Bearer <member_token>" -d '{"tier":"auto"}'` → 返回 200；② 另一用户 B 的会话档位随之变为 auto。
- **预期行为**：成员不能修改全局默认档位；用户 A 的档位变化不影响用户 B。
- **修复内容**：RL1-02——档位改用户级（用户自选 + admin 管全局默认），写口加守卫。
- **测试证据**：（待修）W6 扩/W11：「member 改全局档 403」「A/B 档位隔离」断言。
- **状态**：⬜

### A-2 ｜P0｜ 授权回填无任务/用户归属校验

- **落点**：`app.ts:878-886`（回填路由只查登录）、`permissions.ts:262`（requestId=`pr-时间戳-6位随机`，可预测）
- **复现步骤**：用户 A 的任务弹出授权卡，抓到 requestId（或按格式枚举猜中）→ 用户 B 用自己的 token 调 `POST /api/tasks/{A的任务id}/permission`，body 带该 requestId 与 `allow` → 决策生效，B 替 A 批了界外操作。
- **预期行为**：回填校验请求属于该任务且任务对回填者可见，否则 403；决策值白名单（once/session/forever），非法值 400。
- **修复内容**：RL1-05——requestId 改强随机；pending 绑定 `{taskId,userId}`；回填三重校验。
- **测试证据**：（待修）W11：「他人/他任务 requestId 回填 403」「非法决策值 400」。
- **状态**：⬜

### A-3 ｜P0｜ 授权作用域失真

- **落点**：`permissions.ts:69-78`（sessionAllowedDirs/Commands 为进程级全局 Set）、`:255-257`（once 决策顺带 `grantSessionDir`）
- **复现步骤**：① 用户 A 对界外路径选「允许一次」→ 之后同进程内任何用户任何任务再访问同路径**不再弹卡**；② A 选「本会话允许」→ 用户 B 的任务访问同路径直接放行。
- **预期行为**：「允许一次」仅本次生效；「本会话」按任务（用户+任务）隔离，不跨用户/任务泄漏。
- **修复内容**：RL1-06——once 去掉顺带放行；session 集合按任务维度隔离。
- **测试证据**：（待修）W11：「once 二次访问弹卡」「B 任务同路径弹卡」。
- **状态**：⬜

### A-4 ｜P0｜ store 双损坏静默归零 → 注册重开可抢注 admin

- **落点**：`store.ts:75-79`（主文件+.bak 双坏时 `readJsonSafe` 静默返回 fallback）、`auth.ts:44-64`（users 为空 → `needsSetup`=true → 首个注册者自动成为 admin）

- **预期行为**：关键主文件损坏且备份不可用 → 启动态明确报错拒绝启动；绝不静默当空数据、绝不重开管理员注册。

- **测试证据**：（待修）W13：「主坏+bak 好→自动恢复」「双坏→启动拒绝」「双坏→注册不可用」。

### A-7 ｜P1｜ 等待授权挂起不接 abort

- **预期行为**：停止/断连 → pending 即拒并唤醒，循环终止，running/pending/心跳全部释放；等待超 120s 自动拒绝。
- **修复内容**：RL1-07（requestAccess 接 AbortSignal + 超时 + 联动清理）。
- **测试证据**：（待修）W3 扩/W11：「等待授权时 stop → 任务终止且再发消息正常」。
- **状态**：⬜
