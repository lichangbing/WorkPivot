## 当前可用主路径

```text
登录
  → 创建项目
  → 创建任务
  → 上传/引用资料
  → 选择模型、记忆层和工具范围
```

- 记忆管理、冲突确认、遗忘和加载开关。
- 备份、恢复、回收站和回退材料。

## 发布判断

### 可以说是

- PostgreSQL 主链路可运行。
- 核心任务、文件、记忆、知识、Skill、自动化和私有部署路径已打通。
- 已有多层隔离、审批、备份、恢复和自动化测试基础。

### 不可以说

- 已具备完整企业多租户能力。
- 已在任意客户复杂 Office 样版上无损交付。
- 已完成生产长稳、跨设备、完整安全审计和灾难恢复认证。
- 自动生成的 Skill、记忆或规划无需人工核对即可无条件使用。
