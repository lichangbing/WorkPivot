# PostgreSQL 与项目知识库开发清单

更新：2026-09-13。以当前源码、preview.31 发布记录和最新架构设计为依据；旧 M5 清单保留历史，不代表当前全部功能状态。本文未重新探测线上服务。

## 已有基础

项目/任务、聊天与工具调用、账号隔离、Skill 包与市场、MCP、三层记忆编辑、成果版本与本地同步、密码重置及临时密码强制修改已有文件存储实现。不能把它们列为从零开发，也不能将其误认为 PostgreSQL/RAG 已完成。

PostgreSQL 第一批基础已实现并独立验证；正式业务管线尚未切换。项目知识库、RAG、结构化事实模型及完整版本/遗忘机制仍未实现。已有记忆编辑/删除不等同于跨来源、索引、历史和缓存的完整遗忘。

实现记录：[K01数据库基础第一批](K01-数据库基础实现记录.md)。尚未替换现有部署。

## 必须开发

首版范围：前后端分离，PostgreSQL/pgvector、文件、聊天、记忆与执行全部在后台；多个用户各自独立使用。客户端只交互和展示，保留必要设置及可选成果下载/同步，不持久化知识库和过程资料。团队信息同步后续开发，首期预留项目成员/作用域与变更事件。详见[服务端集中存储与项目组协作预留](../02-design/architecture/服务端集中存储与项目组协作预留.md)。用户端不安装本地后台、数据库或RAG服务。

新增插入当前批次（数据库版本待实现；现有文件后台已交付任务删除）：

2026-09-13 preview.32 已在远端交付普通/临时任务删除入口及任务私有数据清理。运行任务需先停止；共享项目材料和项目/个人记忆保留；未实现项目级联删除、数据库删除状态和对话分页。详见 `releases/v0.3.0-preview.32/README.md`。

- **K01-D 会话/项目删除**：用户删除后后台关联消息、任务、资料、成果版本、记忆和索引同步进入清理；停止在途执行，防止重新写入，处理共享引用、幂等重试与清理状态。文件/RAG部分随K02/K03/K06接入。
- **K01-P 对话分页**：首次仅加载最近5轮，上拉每次加载更早5轮；补充轮次模型、稳定游标、流式去重、滚动锚点及大输出限制。前后端一并实现，不允许前端下载全量再截取。

详情及验收：[会话项目删除与对话分页](../02-design/architecture/会话项目删除与对话分页.md)。5轮按用户提问及对应回复/思考/工具调用归组；客户端展示分页不限制服务端模型记忆范围。

后续版本 K09：项目组成员与角色、显式共享、统一服务器上的增量信息同步、并发冲突、撤权与删除传播。各自离线编辑后的双向合并另行规划，不作为首版任务。

顺序：K01 → K02 → K03/K04 → K07；K05/K06 从底层建模开始贯穿开发；K08 随基础设施建设。功能逐批交付，不等全部完成才验证。

K07 细分为：增量处理基础、任务记忆更新、项目记忆更新、个人记忆更新、用户控制、加载与一致性。首版默认任务自动更新，项目明确且无冲突信息自动更新，个人仅自动处理用户明确的长期要求；推测和冲突进入待确认。详见[三层记忆自动更新](../02-design/architecture/三层记忆自动更新.md)。

不开发旧数据迁移、JSON导入、双写或历史ID映射；采用新库和独立文件命名空间。不迁移不意味着自动删除旧部署。额外专业 Skill、跨项目自动关联不作为本轮首版门槛。

## 验收与交付（区别于尚未开发功能）

- 新数据库下原有账号、任务、Skill/MCP、记忆和成果同步回归；管理员不能读取其他用户知识。
- 删除会话/项目后后台关联数据实际清理，运行/上传并发不复活、共用文件不误删；首次5轮与上拉分页不重复、不漏消息、不跳动。
- 真实文档上传→解析→跨任务检索→结构化计算→成果生成→本地同步全流程。
- 中文检索命中/引用正确性、更新不混版本、删除后不重学、并发修改与索引失败恢复。
- 三层记忆正确归类、增量幂等、手动锁定、分层更新/加载开关、变更可撤销；关闭或删除与后台写入并发时不回流，不把模型推测当作确认事实。
- 断网、任务取消/超时、进程重启、数据库短断、磁盘不足和多用户并发。
- 数据库及文件联合恢复演练、升级与回滚策略验证。
- Windows 覆盖安装保留连接设置与同步目录；现有安装包不等于覆盖升级验收完成。
- macOS DMG 尚未生成；需 Mac 构建和真机验收。如纳入同次 RC 则是交付门槛。
- 最近记录（2026-09-13）：本机 preview.31、公网 preview.32，远端升级前已备份，公网健康检查、页面和未登录访问保护通过；本计划中的数据库原型尚未部署。

按用户纠正，撤回前后台同机部署计划；首版恢复前后端分离部署、服务器升级、目标公网链路和数据持久化验收。K09 项目组协作仍不作为首版 RC 门槛。

新增 PostgreSQL/RAG 属于实质架构与功能扩展，RC 不能继续只按旧文件存储版本的验收结果判断。
