# 跨轮记忆整理（2026-09-19）

本批延续逐条记忆管理，增加对同一任务最近用户对话的参考。后台仍只创建待确认建议，不自动覆盖有效记忆。

## 已实现

- 每次整理带入本轮消息及此前最多五轮已完成、未撤销的用户消息，按时间顺序排列。总原文预算 24,000 字符；遇到超长轮次停止扩展，避免截断后误解。
- 不读取未来轮次、其他任务、助手或工具输出。只针对本轮新表达、补充或明确纠正提出建议，简单确认和寒暄不触发旧事实重提。
- 保留本轮逐字证据及所有参考轮次。确认卡可展开查看参考对话；参考记录表示提取上下文依赖，不表示每句话都支持候选事实。
- 创建和确认建议时检查各轮归属、顺序、原文及撤销状态。确认后所有参考运行均写入记忆来源关系，继续沿用来源任务删除和遗忘机制。
- schema 26 添加建议上下文列及清理触发器：接受、拒绝、失效后清除冗余上下文原文。原有建议兼容空上下文，已有迁移校验值不变。
- 已拒绝的相同指纹建议不重复出现。已有确认记忆仍通过语义比较生成修改建议，需要用户再次确认。

## 后续边界

- 这是有界的近期对话整理，不是遍历全部历史或向量检索。
- 内容识别仍取决于配置模型；语义相近但措辞不同的已拒绝建议，没有完整的语义拒绝库。
