## 回退操作

代码回退（保留当前工作区改动以便对比）：

```sh
git switch --detach baseline-20261020-pre-dsh
```

并行查看而不动当前工作区：

```sh
git worktree add ../workpivot-baseline baseline-20261020-pre-dsh
```

放弃全部未提交内容、硬回到基线（会删除手机端未提交成果，执行前确认）：

```sh
git reset --hard baseline-20261020-pre-dsh
git clean -fd code/apps/mobile
```

数据库回退边界：schema 26→52 全部是增量迁移，**只回退代码不会回滚表结构**。需要完整回退到旧数据状态时，使用对应发布目录 `local-runtime/releases/<构建号>/backup` 内的数据库与文件备份恢复，不能只靠 `git checkout`。
