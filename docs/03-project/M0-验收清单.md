## 人工彩排（GUI + 真模型）

- [ ] **R1 启动与登录**：`pnpm --filter @workpivot/desktop start` → 注册（自动成为管理员）→ 退出 → 用管理员建一个成员账户 → 成员登录成功
- [ ] **R2 模型配置**：模型设置 → 配置本地 Ollama（`http://127.0.0.1:11434/v1` + 模型 ID）→ 验活通过
- [ ] **R3 主流程**：新建任务 → 发消息「列出当前目录文件，读取其中一份并总结」→ 观察流式回复、工具调用行、右栏文件清单
- [ ] **R4 交付物**：让它生成一份 Word 报告（docx-report 技能应生效）→ 双击用 Word/WPS 打开正常 → 成果区版本链可见
- [ ] **R5 权限**：让它读取任务目录之外的文件 → 授权卡弹出；让它执行 `rm -rf 某目录` → 被拦截；`~/.workpivot/audit/` 中可查到上述全部决策
- [ ] **R6 断点续跑**：任务运行中直接杀掉进程 → 重启应用 → 任务显示「已中断」→ 继续任务 → 无重复工作地完成
- [ ] **R7 断网全流程（C03 验收）**：拔外网（或关代理），全程使用本地 Ollama 模型重跑 R3+R4
